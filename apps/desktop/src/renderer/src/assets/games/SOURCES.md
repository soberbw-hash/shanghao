# Game artwork sources

The game marks are bundled locally so room rendering never depends on a live network
request. They are used only to identify a game detected on the user's own computer.

- Steam capsule artwork: official Steam store CDN (`capsule_231x87.jpg`) for Kingdom
  Rush, Slay the Spire, Delta Force, Counter-Strike 2, Dota 2, Apex Legends, PUBG,
  Overwatch 2, NARAKA, GTA V, Rainbow Six Siege, Monster Hunter: World, Black Myth:
  Wukong, Lost Castle 2, Elden Ring, It Takes Two, Palworld, Overcooked 2, and Red
  Dead Redemption 2.
- Minecraft: `minecraft.net` official site icon.
- League of Legends and VALORANT: Riot Games official site/press assets.
- Genshin Impact and Honkai: Star Rail: HoYoverse official site icons.
- Fortnite: Epic Games official launcher logo asset.

All game names, logos, and artwork remain the property of their respective owners.
