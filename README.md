# 上号 ShangHao

给朋友一起开黑的 Windows 语音房。支持五人语音、屏幕分享、本地录音、AI 转录与内容整理。

[下载当前正式版 v3.4.12](https://github.com/soberbw-hash/shanghao/releases/latest) · [问题反馈](https://github.com/soberbw-hash/shanghao/issues)

此仓库仅用于公开下载、界面展示与问题反馈，不包含应用核心源码。应用源码在独立私有仓库维护。

## 下载与使用

支持 Windows 10 / 11 x64。下载 Setup-x64.exe 安装，或使用 Windows-x64.zip；校验文件为 SHA256SUMS.txt。现有下载和自动更新入口保持原地址。

手机号验证注册并登录后，可创建私人房间，或通过频道号找到朋友并加入。AI 云端服务需要有效的对应配置；本地模型按需下载。

## 主要功能

- 五人语音、降噪、按键说话及成员独立音量。
- 屏幕分享、聊天、快捷语音与音乐。
- 本地录音、标记、云端或本地转录及内容整理。
- AI 房间问答与按房间隔离的记忆。
