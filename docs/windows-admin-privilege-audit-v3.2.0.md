# Windows 管理员权限专项审计（v3.2.0）

审计范围：当前本地源码；没有修改程序清单、安装器或实际系统权限。`apps/desktop/electron-builder.yml` 仍将 `requestedExecutionLevel` 设为 `requireAdministrator`。

| 功能                           | 当前实现                                                                                                                | 管理员权限判断                                                           | 后续边界                                                                   |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ | -------------------------------------------------------------------------- |
| 防火墙规则修复/移除            | `windows-firewall.ts` 通过 PowerShell 调用 `New-NetFirewallRule` / `Remove-NetFirewallRule`，只操作 ShangHao Network 组 | 写入系统规则需要提权；只读检查可在普通令牌下尝试，但部分机器策略可能限制 | 仅写入操作放入按需提权 helper；保留失败提示和手动修复入口                  |
| Windows 外观实验功能           | `windows-icon-overlays.ts` 修改 HKLM Shell Icons，并重启 Explorer；当前已有 `RunAs` 按需提权                            | 需要提权，且影响整机及其他窗口                                           | 保持显式用户点击和备份/恢复；未来由 helper 承担，主程序无需因此全程提权    |
| 旧版开机任务清理               | `windows-startup-task.ts` 删除旧 `ShangHao Auto Start` 计划任务                                                         | 取决于旧任务的所有者和权限；不能假设普通用户一定可删                     | 一次性迁移失败可重试，未来仅此操作按需提权；不要为清理任务抬高整个应用权限 |
| 常规网络与 Phone Mic           | ws/WebRTC/ICE、浏览器配对、USB ADB 转发                                                                                 | 常规连接与 ADB 不要求管理员；防火墙规则修复是独立写入操作                | 保持媒体和信令在现有进程，不迁入 helper                                    |
| 游戏探测与 Rust Core           | Toolhelp 快速枚举；候选 PID 才查进程路径；异常可回退 PowerShell                                                         | 同权限进程通常可查，受保护或更高权限进程可能拒绝路径读取                 | 对拒绝访问降级为进程名/窗口名与 fallback；不得为提升匹配率强制全程管理员   |
| 全局快捷键、电话模式和音频设备 | Electron/Windows 音频 API 与已有辅助进程                                                                                | 常规桌面交互不需管理员；对高完整性进程的快捷键可存在 Windows 隔离限制    | 实机验证普通权限下的覆盖范围，不以推测更改安装清单                         |
| 屏幕分享、录音、模型和更新     | Electron 捕获、用户数据目录文件与后台下载                                                                               | 正常用户目录操作不需管理员；安装器/受保护安装位置更新可能触发 UAC        | 更新仍须用户点击安装；先验证现有安装方式和升级路径，再考虑降权             |

## 风险与迁移顺序

1. 先在隔离 Windows 测试账户中验证普通令牌的登录、双房间、五人语音、屏幕分享、录音、Phone Mic、更新及游戏探测；记录拒绝访问的确切 API 和 PID。不要在真实用户资料目录试验。
2. 设计只暴露固定命令的 privileged helper：修复/移除本程序防火墙规则、修改/恢复图标标记、必要的旧任务清理。每个命令校验调用方、参数和目标路径，不接受任意 PowerShell 字符串。只在用户明确触发系统级写入时提权。
3. 验证 helper 失败、UAC 取消、更新替换、卸载和回滚，再评估将 EXE 清单降为普通权限。此步骤需要单独发布计划与真实 Windows 升级验收。

当前全程提权扩大了主进程及其子进程对系统的写入能力，且可能令本地 AI 环境生成不便于普通用户读取的文件。直接降权又可能影响已有防火墙修复、旧计划任务及更新路径，所以本轮保留现状。
