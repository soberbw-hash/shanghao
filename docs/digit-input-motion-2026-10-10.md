# 数字输入动效

参考用户提供的《验证码功能应该这么设置》本地视频（5.33 秒）：逐格焦点、提交收拢、成功勾号及毛玻璃层次。采用上号既有浅色风格，背景模糊保持静态，位移与透明度由 GSAP 单独管理。

## 已接入

- 注册验证码、找回密码验证码：只在实际注册／重置请求中显示检查动画；请求失败后回到可编辑状态，既有账号成功跳转不为动画等待。
- 查找频道号：查找请求触发收拢，真实结果触发勾号并回填号码；找到房间后仍需点击加入。
- 创建频道号：随机号码请求与可用性检查显示加载，服务器确认可用后显示成功反馈。创建操作保留原提交流程。

输入保留为单个原生文本框，显示六个视觉数字格。支持完整号码粘贴替换、空格清理、全角数字、开头零、退格、方向键、全选和单格替换。减少动画偏好使用短淡入淡出，不做空间收拢或错误位移；沿用全局隐藏页视觉暂停。

## 适合继续采用的地方

复制房间邀请、保存房间设置、导出文件，可使用“操作图标 → 处理中 → 完成勾号”的短反馈；它们不需要六格输入。手机号、密码、房间记忆等长文本保留普通输入，避免干扰阅读与编辑。

## 当前证据

TypeScript、定向 ESLint、diff 空白检查通过。浏览器预览查看六位输入、开头零、单格修改、全角含空格粘贴、收拢加载及成功回填；账号样式下验证码和获取按钮没有叠加外边框。

没有运行测试套件，也没有调用真实短信、账号或房间服务器；预览按钮仅切换组件视觉状态，不代表真实账号流程已验证。版本保持 3.4.4，未打包或发布。

## 预览完成状态与保存反馈补充

修复预览页点击查找后停留在检查中的问题：预览使用可取消的 1.1 秒模拟检查，随后自动播放勾号与数字回填；失败预览同样先检查再回到错误状态。编辑／重置会取消旧计时，操作中禁用重复预览。真实数字输入组件仍由请求拥有者提供状态，不采用固定时间冒充请求完成。

新增通用操作反馈图标并接入房间记忆保存按钮：保存图标 → 请求中旋转图标 → 服务端确认后的勾号／已保存。刷新记忆与保存分别显示，不增加真实操作延时。浏览器预览已观察从检查中自动进入检查通过；真实记忆保存尚未调用。
