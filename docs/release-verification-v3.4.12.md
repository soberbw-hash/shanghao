# 上号 v3.4.12 发布核对

本轮用户已授权修复、统一检查并按桌面流程发布。当前文件记录构建前证据；GitHub 与官网资产未全部下载核对前，不声称本版已发布。

## 修复与证据

- 模型面板：四种文本选择、三种转录来源共 12 组同排等高；700 像素窄屏自然堆叠、没有横向溢出。预设先编辑草稿，保存后才改变实际提供方；跨源保留密钥被拒绝且原文件不变。
- DeepSeek：核对[官方接入文档](https://api-docs.deepseek.com/quick_start/)与[10 月 17 日公告](https://api-docs.deepseek.com/zh-cn/news/news261017/)，`deepseek-flash` 对应 V4.1-Flash-1017。未提供 DeepSeek 密钥，未宣称实际请求成功。
- 转录失败：真实旧日志中，模型对比在推理前被 `remote_asr_model_comparison_not_supported` 拦截；另有一次云端 HTTP 500。已将显式本地对比与默认云端路径分开，并增加仅针对瞬时故障的有界重试。
- 当前源码真实短语音验证：SenseVoice HTTP 200、ready；Paraformer 在默认云端配置下运行本地模型对比，60.3 秒完成，1 段、0 失败、0 次云端上传。只读复用模型，结果和配置使用独立临时库；未运行用户的 94 分钟真实录音，也未宣称八种模型全部完成真实推理。
- 自动处理：新配置默认转录、整理、清理开启，明确旧偏好保留；自动上传仍关闭。缺少 API 密钥或本地模型未安装时保留 pending，等待准备，不把录音当成识别失败，也不自动下载大型模型。定向等待与恢复门槛检查通过。
- 发布前独立复核补上逐条录音的整理授权持久化：恢复不再固定整理，旧记录缺字段默认只转录；同时遵守当前全局开关。文本密钥未配置时保留完整转录和统计，恢复只整理、不重复识别；未就绪但已开启的自动开关可关闭。七项回归先失败、修复后通过。
- 录音播放器：实际组件、合成音频夹具测得四处红蓝中心误差 0.51、0.59、0.58、0.71 像素；提示在独立 24 像素行内，2.5 秒后消失而不跳版。只保留自动废录音清理开关，收藏和标记录音保护保留。
- 随机频道号：一次点击从两轮检查减少到一轮，动画继续当前姿态、布局集中读取；前导零、手工输入、错误恢复及隐藏页暂停通过。
- 进房：原音效同步合成约 19–26 毫秒，移入 Worker 后约 0.3–0.5 毫秒；立体声每个采样相同，输出路由、取消与过期抑制通过。生产构建 file:// 与正式 CSP 可以加载 Worker。
- 通知：系统总开关关闭已实际复现与修复，原生探针从系统拒绝变为 Enabled 且两秒内未拒绝；只改总开关，勿扰模式仍开启，未承诺横幅必弹。添加有界通知生命周期、一次失败反馈和系统设置入口。
- 电话与天气：进入提示音在上号发送门控后、原生静音前播放，代际检查防快速松键后迟到开启；原生确认后才提示成功。天气移除重复控件，实时路径和手选城市保留。详细现场证据见[追加需求记录](user-request-checklist-2026-10-19-followup.md)。
