# 云端长录音与可选本地辅助

这轮修改位于本地开发版，尚未发布新版本。

## 修复范围

- 云端纯文本按句判断语言；一句非中文内容不会再把相邻中文的整个五分钟片段丢弃。整段解码循环、乱码等质量保护继续保留。
- 每个云端分段的原始回复仅保存在本机录音记录中。继续任务可以复用回复并重新解析；明确重新转录或清理结果会清除对应缓存。自定义接口地址或模型变化后不复用旧接口缓存。
- 长片段空回复按三十秒复核，静音小片段不重复上传。未返回文字仍会显示复核提示，不能把“请求完成”解释成逐字准确。
- 整理器的块级参与者只引用该块原文；汇总请求不再重复携带整场参与者引用编号。空汇总不能发布为成功，已完成的分块可以继续使用。
- 文本 API 的整理请求采用有界三分钟期限；问答保持一分钟。取消、网络错误和超时使用独立错误状态。
- 任务在失败或取消后重读记录时，必须核对本任务最后成功保存的版本。外部实例、新任务或人工修改推进版本后，旧任务不能覆盖其结果或任务状态。

## 云端＋本地辅助

按用户最新决定，自动转录与“云端＋本地辅助”均默认开启，保留已保存的明确关闭偏好。录音库与 AI 功能共用开关和独立的辅助模型选择，仅在云端/自定义 API 模式显示。辅助模型默认 Qwen3-ASR-0.6B＋ForcedAligner，也可选择更强的已支持本地模型，不改变纯本地转录的模型偏好。所选模型未下载或未就绪时提示下载/准备，本次只保留成功的云端结果，不自动下载、不静默换模型。旧 Paraformer 任务恢复仍锁定原模型和检查点；早期 Paraformer 实测不能代表千问的新链路已经实测通过。

启用后先保留云端结果，再通过现有本地任务调度生成第二份识别。千问的本地原稿使用其强制对齐时间；它并不代表云端原稿已经对齐。整理以本地原文引用为准，并附上同时间范围的有界云端文字参照；长参照标明节选，两份完整识别仍保存在本机。自动融合稿仍未交付，不能把两份全文拼接称为校对。

新增文字来源栏及云端／本地原稿切换，显示实际产出模型，不根据当前全局模型偏好猜来源。融合前自动显示云端并明确其片段内估算位置。自然段内部按实际点中的句／词起点回听，修复过去整段所有文字都跳段首的问题；不通过人为固定偏移或大模型编造时间。

旧录音可以点击“本地辅助校对”，复用已完成的云端分段。自动处理过长录音时本地辅助仍遵循资源限制，可由用户手动继续；本地失败时保留云端及本地检查点。取消必须中断实际工作，完成后释放本地 ASR worker。

录制时已有独立成员音轨/语音片段的，沿用原有身份绑定。只有混音的旧录音，Paraformer 不会凭空得到可靠人名或多人分离能力。两份识别的差异也不等于其中一份必然正确。

## 实际验证与边界

- 使用真实 3 小时 42 分 53 秒录音完成 45 个云端分段：修复前保留 458 句段、5,563 字符，修复后为 2,047 句段、25,915 字符。原始回复为 26,272 字符；44 段非空回复均保留了可用文字，另有一段空回复。旧结果已先备份，原音频未修改。
- 使用真实一分钟录音跑通云端＋本地 Paraformer，保留两份结果及本地逐词时间信息。该样本验证功能链路，不代表整场录音逐字或逐人准确。
- 补全后的整条长录音已通过真实 GLM 完成 28 个整理块和最终汇总，生成 6 条摘要、8 个章节并保存回录音库。保存前后逐段文字拼接校验一致；原始音频和组织前备份保留。
- 另行验证了真实 AiTextGateway、原录音房间记忆读取及 GLM 请求，避免仅验证直连接口而遗漏房间上下文依赖。测试不把“模型请求成功”当作人工准确率验收。
- 自动化覆盖真实共享存储版本变化、空回复复核、混合失败与取消、同任务外部修改、暂停旧任务、两页设置同步及 N-1 可选字段兼容。

诊断只保留状态与有界统计，不输出转录正文、音频、房间对话或凭据。
