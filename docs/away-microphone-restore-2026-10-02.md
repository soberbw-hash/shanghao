# 离开返回保留麦克风状态

## 原因与修改

返回逻辑原先只检查 `isDeafened`，扬声器开启时一律解除静音，丢失了用户离开前手动静音的选择。

- 自动离开与手动离开都在强制静音之前保存麦克风状态。
- 鼠标活动自动返回、点击座位手动返回都恢复该状态；重复点击离开区域不覆盖首次保存的状态。
- 当前关闭扬声器或电话模式仍保持静音。缺少离开快照时保守保持静音。
- OS 挂机时间查询失败不再当成“0 秒”，避免查询失败触发自动返回和恢复麦克风。
- 不改变三十分钟阈值、手动离开不会因鼠标自动返回的规则、音频处理或房间协议。
