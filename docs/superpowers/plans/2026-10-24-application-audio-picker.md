# 共享声音选择窗口

按用户截图修复原底栏 popover 被聊天面板遮挡的问题。延续现有浅蓝/HarmonyOS 风格，使用原生顶层 dialog 并挂载到 body，避免房间 transform/overflow/z-index 干扰。

- 声音弹窗采用应用缩略图列表 + 已选应用确认区；以音乐/声音图标、青蓝强调和“只共享声音”区分屏幕共享。没有显示器页签、清晰度或远控入口。按钮为“共享此应用声音”。
- 真实窗口缩略图和图标只用于本地选择，不发送给房间。Main 通过原生枚举的 HWND 与 Electron 窗口 ID 精确匹配，不用同名标题猜测；最小化/受保护/旧 helper 无预览时明确降级，仍可选择应用。
- Main 仍拥有 opaque source ID 和 PID + creationTime，开始前保持进程身份复核；预览不赋予屏幕分享或输入权限。不新增系统音频捕获，不改当前音频混音/发送链路。
- 处理加载、空列表、错误重试、源消失、刷新、取消开启、正在分享/音量/停止和键盘 Escape/焦点返回。关闭选择窗口不停止既有分享，开始中的取消真实停止 pending work。
- 先做精确映射/异步列表归属专项，再隐藏 Electron 实测遮挡、选择、空态、取消、键盘和窄窗口；类型/lint/build、相关音频回归。完成本轮自检后提交既有“上号审核”。用户截图显示录音中，未经安全确认不重启现有开发窗口或打断录音。
