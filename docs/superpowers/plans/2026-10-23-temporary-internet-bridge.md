# 临时房间公网桥接：接续实施方案

状态：已按下述反向 WSS / 内层 TLS 边界实现，并完成临时领域 73/73 隔离自检。具体实现、命令与未验证范围见 [桥接证据记录](../specs/2026-10-23-temporary-internet-bridge-evidence.md)。仍须由主任务完成最终整合检查及统一审核；保留用户暂停发布要求。

## 已验证的基线与缺口

实施前临时房间已复用现有媒体服务器与客户端，LAN 私密复制和多数故障迁移已有隔离进程证据，但公网与 LAN 仍是两个协调者。现已改为 Main 持有唯一临时协调者，公网经受限管道到达同一个服务；同码不同 Session 继续明确拒绝。

需求书 7.5 明确要求：本地房间公开到互联网时注册同一 Session，处理全局码冲突、同步换码、保留已有连接。只做云端故障后新建 LAN 房间不满足该要求。

## 采用的边界

保留已选出的 Main 协调者及其唯一 SignalingServer。新增受限的反向 WebSocket 管道，让互联网成员经现有服务器到达该 Main 的临时 TLS 服务；局域网成员仍可直接连接它。两条路径进入同一协调者、同一 RoomManager，避免维护两个可独立接纳成员的副本。

内层继续使用 Main 临时证书的 TLS/WebSocket。外层管道只传字节，不解析、记录或改写入房 proof、票据及媒体消息。Main 只能把管道接到自己实际启动、固定代际的临时服务端口，禁止 renderer 提供目标地址或任意 TCP 转发。现有 Peer、语音处理器、录音 Track 和远程控制授权逻辑不另建第二份。

## 实施顺序

1. **Broker 与目录。** 新建独立 signaling 模块，复用固定域的设备 challenge/PoP；注册 Session/authority/epoch/八位码和临时证书指纹。限定每身份、来源及全局数量，目录查询须限流和认证，不提供枚举。与现有 coordinator 的有效码共同检查冲突。连接断开、TTL、最后成员退出时失效。相同 Session 的更高 epoch 必须验证原权威 checkpoint 与严格多数移交证书，不能凭客户端宣称覆盖旧注册。
2. **受限管道。** 每个消费者生成随机、短时、一次性的管道 ID/secret，仅在 WSS 消息体传递，不能放入 URL、UDP、日志或 renderer。主持控制连接收到开管请求后另建固定外层 WS；broker 配对两端并转发二进制，设置尺寸、连接数、速率、缓冲上限和超时，关闭任一端立即收尾。消费者使用内层证书 pin 建 TLS，broker 知道管道不等于获得成员身份。
3. **Main 适配。** 原 TemporaryRoomClient 的受控 socket factory 支持异步管道准备；Main 的 descriptor 仍只给 renderer 不透明 context。公网查码先得到经认证的 Session/authority/epoch，再绑定路由；LAN 查询与公网结果同码不同 Session 时拒绝静默选择。旧服务器不支持桥接时明确安全降级，不能显示已开放公网。
4. **私密复制与故障续接。** 每名成员的 Main 复制端点也可通过受限管道到达。保留既有多数租约、成员移除 fence 和私密 checkpoint 校验；不得因公网可达而绕过多数，或让旧主持重新抢回。新主持注册必须带移交证据，原 Session/memberId 保留，新 proof/票据重发。公网中断时 LAN 继续；公网恢复不能复活已关闭会话。
5. **发布与同步接线。** 当前主持在可用时注册互联网目录；遇全局码冲突，经过当前权威的管理路径换码并同步现有成员。只改变查找码/信令到达路径，不重新创建 Session 或全房重置媒体。主持离房但其他人仍在时保留服务或完成受证书约束的移交。

## 必须先跑通的隔离测试

- 实际独立本地 TLS 协调者 + 独立 broker + 两个消费者，经管道完成真实临时认证及既有媒体信令；LAN 直连成员与公网管道成员看到同一成员表/Session。
- 码冲突不覆盖其他 Session；更换后原成员看到新码，已有成员 ID 不变；同码不同来源不能被静默选中。
- 伪造/过期 PoP、他人管道 ID/secret、重复配对、旧 epoch、回滚 checkpoint、非多数移交、被踢成员都不能重新注册或接管。
- 主持进程崩溃、旧主持网络分区、只剩少数、互联网中断/恢复；已有 LAN/P2P 媒体保持各自生命周期，禁止第二个 writer。
- 过载、半开、慢消费者、取消、旧代际异步回调和退出释放；broker 不保留或输出正文/音频/票据。
- 现有五人媒体、永久房间权限与云数据隔离回归。真实双机、不同 NAT/TURN 与耐久仍单列，不能用本机管道测试替代。

只有上述接线和自检完成后，才能勾选总计划中的公网/LAN 统一会话项；不因为纯目录或管道单测通过提前宣称完整交付。
