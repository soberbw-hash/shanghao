# 3.4.13 收尾、发布与闭源迁移准备计划

**Goal:** 收尾外部评审中可在本机落实的改进，将当前完整工作区验证后发布下一修订版，并准备不破坏下载和更新的闭源迁移。

**Architecture:** 保留已验证的媒体路径。录音检索复用本地语音记忆搜索、永久 RoomID 和已有播放／片段导出，不重转录、不上传。设置普通开关即时保存，文本模型表单显式保存。源码权限和二进制分发分离。

**Spec:** 用户提供的 3.4.12 全面评审、2026-10-20 的“全部搞完后发布下一版本，再闭源并保留公开下载”要求；当前核对见 `docs/review-v3.4.12-local-2026-10-20.md`。

## 约束与决定

- 当前脏工作区是唯一最新基线，复用此工作区；不重建、不从远端覆盖、不让代理各自提交。用户最新明确要求暂停发布，修改完成并由用户确认后才可发布。
- 不提高架构预算；不为 UI 建立新的媒体／诊断平行系统；不删除任何用户数据。
- 清理已获用户选择：只自动清理确认整段静音的录音；有声短录音保留，容量阈值不能绕过静音验证。
- 用户已确认自研版权均归其所有，并在暂停新版发布期间另行明确授权“更改成不开源”。源码改为私有维护，未公开的自研代码及后续版本使用专有许可；已公开版本的既有授权不能靠私有化撤销。3.4.13 发布仍暂停，既有正式版下载迁移不属于发布新版本。
- GitHub 与官网线上基线一致后，才确定下一补丁号；目前本地与已记录正式版为 3.4.12，候选 3.4.13。
- 真实多机、游戏全屏、RØDE、FPS、旧客户端升级不能由单机自动测试替代。
- 所有测试与截图使用隔离演示数据，不把真实录音或正文放进发布资产。

## 执行与验证

1. **已完成的模型及隐私修复**：保持文本模型显式保存、当前使用提示与转录数据去向说明。`electron-recording-model-sync.cjs` 覆盖保存失败重试、双向同步与混合辅助入口。
2. **录音内容检索**：修改 `RecordingLibrarySettingsCard.tsx`，新增职责单一的检索控件／筛选模块；复用 `desktopApi.ai.searchMemory`。房间、日期、转录状态筛选；关键词结果显示来源与原始位置，选中结果连接当前录音回放与既有片段导出。显式触发检索、取消迟到结果，不在每次刷新扫描正文。定向测试覆盖跨房间过滤、日期边界、无转录、迟到结果和估算位置说明。
3. **首页与设置层级**：`PrivateRoomBrowser.tsx` 中上次房间只保留一个主进房动作，保留收藏、查找、创建；AI 低频模型管理与 API 配置可展开，当前模型与自动开关保持直接可见；设置栏目增加常用／进阶分组。保持现有样式体系，清理未使用主题定义的歧义，不改实时音频。验证 keyboard、重复进入、模型表单保存和布局。
4. **麦克风状态与剩余边界**：核对现有采集、设备、连接诊断，能够可靠辨认的问题复用现有状态展示，正常安静不提示设备故障。本轮不凭本机采集推断远端听感。
5. **清理**：用户选择新规则后才补失败回归并实现；声音不明、读取失败、收藏、标记继续保护。容量回收另行说明，不执行真实清理。
6. **完整验证和版本资产**：对应定向测试、全量 smoke、类型、lint、媒体链路及正式发布流程检查；运行本轮受影响的原生页面检查，截首页、录音搜索、AI 设置及混合模式等干净截图，更新版本说明和 README。构建安装器、ZIP 与哈希，保留历史版本。
7. **发布**：按桌面 `重装必备资料/02_发布规范/发布说明.md`，先 GitHub Release／CI，再 CloudBase 下载和 manifest，实际下载校验后报告完成。若需新授权，仅停在相应外部写入，继续完成独立准备。
8. **闭源迁移方案**：核对版权、第三方许可、现有更新 URL 与公开仓库影响；准备私有源码库／公开分发库的迁移清单，验证下载与升级过渡后才切换仓库权限。没有用户版权答复及具体迁移确认前，不删除历史／改许可／隐藏现有库。
