# 云端 AI 管理

目标：让管理员可视化查看、添加、修改、停用和删除云端文字及语音服务配置。普通用户继续使用既有云端接口，第三方密钥只保存在服务器。

背景：原有文字与语音服务从进程环境变量读取配置；本地改动增加了服务器私有配置及运行时更新。账号令牌验证仅证明账号身份，不能自动赋予管理权限。部署在 GitHub 的源码与客户端不能包含管理凭据。

实施边界：服务端使用服务器私有配置指定管理员账号稳定 ID，逐个管理请求重新验证令牌并检查该 ID；默认无管理员时拒绝全部管理操作。配置保存在服务器专用目录，访问权限受限，原子写入并保留可恢复的加密或受限备份；密钥只接受写入和替换，不回显原值。后端拒绝私网、环回和链接本地地址以及重定向，限制请求尺寸、速率和并发；审计只记录操作、时间和结果，不记录密钥或请求内容。

修改先验证，再以明确操作应用；启用、停用、删除需明确确认，避免影响正在进行的任务。实现需要考虑现有环境变量迁移、运行时服务对象更新、崩溃恢复、并发修改和在线任务隔离；不能只修改显示而继续使用旧值。入口与现有服务器部署边界需按用户选择确定。

入口决定：放在上号的 AI 功能设置中；仅在已登录账号通过服务端管理员权限检查后显示。普通账号看不到入口，但隐藏入口不作为权限保护：查看、增删改和应用配置的每次请求都要在服务端重新认证和授权。登录失效或检查失败时收起入口并清除页面缓存。

管理页按文字服务和语音服务分别列出配置、启用状态与当前模型；密钥只显示是否已配置，留空表示不修改。添加或修改先校验并保存，启用或删除需确认；操作失败时保留当前生效配置。变更只作用于服务器配置，新请求使用新配置，进行中的请求保持原有配置。首版不提供任意服务器文件、命令或其他系统设置的管理。

本地实现状态：已接入账号白名单、配置读写和文字／语音服务路由，AI 设置中可见管理员入口。首次部署需要服务器私有环境变量 `CLOUD_AI_ADMIN_USER_IDS` 指定管理员账号的稳定 userId，并配置 `CLOUD_AI_CONFIG_FILE` 或现有永久房间存储路径；未配置管理员时默认拒绝管理操作。配置文件和上一版本备份只存在服务器，密钥不会通过管理接口返回。支持的服务地址目前限于智谱、硅基流动、DeepSeek 和 OpenAI 的 HTTPS 官方域名。用户尚未完成线上启用及端到端验收，本地实现不代表线上已部署。
