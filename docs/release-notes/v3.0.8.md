# 上号 ShangHao v3.0.8 更新公告

这次把最近集中暴露的长录音、模型测试、AI 整理和房间交互问题一起收口。重点不是再堆功能，而是让已经存在的功能有清楚的状态、可靠的恢复路径和更顺手的界面。

## 🎙️ 长录音不再卡在半路

- 测试任务会保存真实进度与失败位置，暂停、重启或模型异常后可以继续处理。
- “清除本轮状态”现在只清除本轮结果与进度，不会把模型候选列表一起清掉；清除后可以重新选择模型并从头测试。
- 空输出、静音、超时、崩溃和 OOM 分开记录，不能再用一个空字符串冒充成功。
- 十分钟样本和完整录音分别保存测试范围，界面显示任务完成度，不再把语音占比误写成任务进度。

## 📖 精细时间轴，也能像文章一样读

- Qwen、GLM、ARK、Fun-ASR、FireRed、Paraformer、MOSS 等模型统一经过阅读段落展示层。
- 原始 segment、逐字时间和 ForcedAligner 结果完全保留；阅读时才按照同一说话人、停顿和段落长度合并。
- 点击段落、搜索字幕和播放定位仍然回到真实原始时间，不牺牲时间轴精度，也不影响 Benchmark 的 CER 与原始分段统计。
- 上号原生录音直接使用真实成员、昵称和音轨身份，模型自身的 Speaker 标签不会覆盖软件已经知道的人。

## 🧠 本地 AI 状态更直白

- 模型下载、校验、运行时准备、加载和失败原因使用统一状态，普通用户不再面对“FreeToken 待启动”这类无法操作的内部术语。
- Qwen3.6 本地整理在使用时自动准备运行环境，长文本按自然停顿和话题边界分块，并保留可跳回录音的时间引用。
- 整理结果默认只保存在本地；只有用户明确点击上传后，昨日房间等服务器功能才会读取。
- 房间语音优先级最高，开黑时后台转录、整理和下载会主动让出 CPU、GPU 与磁盘资源。

## 🎧 麦克风与房间更顺手

- 麦克风体检和说话模式移到主页麦克风菜单，体检缩短为 5 秒，设备选择固定在菜单底部。
- DeepFilterNet3 降噪保持原有逻辑，并加入轻量 DSP 人声整形；无法稳定直接接入实时麦克风的 LavaSR 不再展示无效开关。
- 登录后进入确认页，由用户选择房间并进入；自动选择未占用角色。麦克风异常会留在当前页提示，不再闪进房间再退出。
- 房间成员短暂网络波动采用稳定收敛，避免人物反复出现、消失和重复播放进出动画。

## ✨ 设置页和常用操作减负

- AI 模型卡片压缩空白、隐藏次要说明并固定状态区域，新增提示不会再把整页布局撑乱。
- 设置切页、图片查看和音频设备菜单减少点击同一帧里的磁盘读取、设备枚举、图片解码和大范围重渲染。
- 界面音效默认开启，移除设置里的开关和音量调节。
- 删除与游戏定位无关的工作软件状态展示及相关资源，活动展示继续聚焦游戏和音乐。
