# 上号 ShangHao v3.1.1 更新公告

这次更新围绕一个目标：让房间更像朋友们正在共享的空间，而不是一组拼起来的面板。我们统一了房间、聊天和底部操作区的玻璃质感与细微光影，也修复了窗户在部分尺寸下被裁切、多人在场却少显示角色等问题。

## 🪟 房间更完整，聊天更融入

- 调整顶部房间栏、快捷消息区、聊天面板与底部 Dock 的圆角、层次和间距。玻璃边缘保留柔和高光与投影，文字和操作仍以可读性优先。
- 修复不同窗口尺寸下窗户偏移或被裁切的问题；窗外天气场景保持动态，隐藏页面时暂停纯视觉工作。
- 房间座位以成员及落座状态稳定映射，减少“人数显示正确、画面少一个人”的情况。
- 注册时选择头像，旧账号没有头像时可分配预设头像；头像通过账号服务保存和同步，并用于聊天、悬浮窗和成员界面。

## 🎮 游戏状态与麦克风

- 优化 Windows 游戏进程探测：缩小昂贵的元数据查询范围，主探测失败时启用轻量回退，并避免一次失败立刻清空朋友看到的活动。英雄联盟与三角洲仍需在各自游戏环境下复验识别结果。
- 麦克风体检改为 3 秒，录制中显示倒计时，同时保持面板高度稳定，减少点击录制后的整体跳动。
- 增加“使用手机麦克风”入口，支持 Web 配对和 USB 路径。Web 配对需要安全的 HTTPS 服务、账号登录及手机浏览器麦克风权限；不同网络和设备仍需实机确认。

## ⚡ 流畅性与兼容

- 将房间聊天气泡的更新范围下沉到需要它的组件，并收紧麦克风电平刷新频率，减少无关渲染。
- 桌面端更新至 Electron 42.11.8；保留现有 WebRTC、音频处理、录音和屏幕分享架构，没有为这次视觉更新迁移用户本地数据。

正式 Windows Release 提供安装器、自动更新所需的 `latest.yml` 和 `.blockmap`，以及 SHA-256 校验文件。自动化五人链路测试不等同于真实好友的听感、公网 TURN、不同手机浏览器或旧版客户端升级体验；这些项目需要分别实测。
