# 上号 ShangHao v3.3.0 更新公告

这一版集中收紧长时间使用中的资源生命周期、失败恢复与用户数据保护，并把本地 AI 和录音相关工程细节补齐。Windows 10/11 x64 是正式支持平台。

## 房间、音频与设备

- 房间 Session、信令回调、设备切换和屏幕分享操作按会话代际管理；旧操作结束得再晚，也只能释放自己创建的资源。
- 麦克风保护分析使用完整连续采样窗口；远端响度学习结合成员说话状态和音频能量，降低键盘、碰撞等瞬态对音量学习的影响。
- 输入设备枚举失败不再误清除用户选择；音频诊断区分设置期望、实际应用和检测到的状态。
- 房间、Relay、音频与 AI 任务可导出有界状态时间线，诊断继续过滤聊天正文、转录正文、音频内容与凭据。

## 录音、AI 与本地数据

- 录音流重复完成、分轨清单损坏、目标文件重名和中断恢复都有明确保护，失败时保留可恢复的原始音频。
- 录音库元数据、Marker、聊天历史、设置、账号会话和语音记忆遇到损坏或写入错误时，不再按空数据覆盖旧文件。
- 转录临时文件采用独立命名和有界过期清理；AI Runtime 安装、下载和长子进程支持取消、重试与有界输出。
- ASR 测试区分模型输出能力与语言、配置、运行时等因素；结果说明见[模型评测记录](https://github.com/soberbw-hash/shanghao/blob/v3.3.0/docs/asr-evaluation-2026-09-27.md)。

## 工程与说明

- 规范 Windows x64 发布资源，新增安装包体积报告与预算检查；不为体积指标移除实时语音、录音、快捷音频或用户已下载模型。
- README 按使用场景介绍产品功能，并说明 WebRTC Mesh、Relay/TURN、DeepFilterNet3、语音保护、说话检测、手机麦克风和 Electron/Rust 职责边界。

## 验证边界

- 本地验证覆盖类型检查、Lint、桌面 smoke、Native 测试、五人音频/媒体模拟与 Windows 构建流程。
- 自动化结果不能代替真实五台设备、USB 热切换、朋友端手机麦克风听感或真实网络恢复。
- 旧版客户端完成“发现 3.3.0 → 下载完成 → 用户点击安装并重启”仍需真实客户端验收；更新不会在后台自动安装。
