# 上号 ShangHao v3.3.1 更新公告

这一版整理现有房间、录音、天气与 AI 任务的稳定性，并修复设置和更新提示中的反馈问题。正式支持 Windows 10/11 x64。

## 房间与日常体验

1. 天气在登录阶段开始预取，提前加载场景资源，进入房间后的场景切换有渐变过渡；天气文字显示具体地点。Windows 精确定位仅在用户明确开启后请求系统权限。
2. 新用户默认配置八个语音／音效和五首音乐，快捷音频默认音量 15%。升级保留原有自定义内容、空槽位和音量，不用默认配置覆盖用户选择。
3. 房间收藏出现新内容时显示红点，打开查看后消失；两间房分别保存已读状态。
4. 设置页移除重复的房间记录入口，保留当天首次开启时的弹窗；通用设置标题与侧栏统一，移除开发者模式和动态天气开关。
5. 修复更新浮窗周围的浅色遮罩，并协调更新提示、发布说明和每日弹窗的显示顺序。诊断的重新检查按钮提供进行中与完成或失败反馈。
6. 录音详情把录制时间放到日期后面，明确区分录制时刻和音频总时长。

## 稳定性与工程保护

1. 成员离开时统一清理音频、Relay、共享与连接缓存，减少掉线和重连后的残留状态；保持现有实时媒体路径。
2. 语音记忆的观察写入、转录单元逻辑拆为独立模块；常驻组件只订阅需要的设置字段，减少无关设置变化带来的更新。
3. 录音 Marker 与 AI 转录 IPC 限制参数、数组与数据大小；Marker 写入检查录音库路径和符号链接，采用原子写入保护原数据。
4. Runtime 下载锁提供有界等待，并处理异常退出留下的锁回收记录，避免其他进程永久等待。
5. Windows CI 与正式 Release 新增真实 Electron 屏幕捕获门禁，检查不同分辨率、停止后的 Track 状态和捕获降级路径。
