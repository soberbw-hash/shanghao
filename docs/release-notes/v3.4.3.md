# v3.4.3 更新公告

## 这次改了什么

- **游戏画面更真实。** 全部 60 款支持的游戏分别配置显示器画面，优先采用官方场景、游戏截图与演示静帧。
- **房间记忆更清楚。** 管理页只保留手动记忆和一份自动记忆，去掉来源卡片、条数和多余说明。
- **记忆接着补充。** 自动提取的新信息加入同一份内容，已有修改保留；不同房间分别保存。
- **分享前先预览。** 应用窗口和整个屏幕分开选，确认清晰度与系统声音后才开始分享；可直接复制房间邀请。
- **素材可以自己审核。** 关于页打开内置上号素材，或创建桌面入口；图标、天气、角色动作分别查看，复制下载并保存意见。

## 分享更清楚

点击来源只选中并预览，不会立即分享。系统声音默认关闭，开启后包含整台电脑的声音；刷新列表保留本次清晰度和声音选择。窗口关闭或来源消失时，开始按钮会禁用。朋友仍需加入同一私人房间后观看，房间权限保持原有规则。

## 素材审核

上号素材随上号安装及更新，在「设置 → 关于上号」打开或创建桌面入口，用浅色耳机图标与主软件区分。品牌图标、房间组件、天气效果、角色动作、游戏显示器、账号头像独立分类；八种天气可切换四个昼夜时段。角色选择「全部动作」可集中查看 85 个预览，也可筛选、暂停和放大，保持原比例。支持复制图片、下载原素材、保存及导入导出意见；滚动正常，升级保留审核记录。

![上号素材的角色动作审核](https://raw.githubusercontent.com/soberbw-hash/shanghao/v3.4.3/docs/readme/v343/asset-studio.png)

游戏画面是静态场景，并非实时捕获朋友屏幕；KK 对战平台采用入口界面设计。旧记忆保持可读，房主编辑权限、版本冲突校验和房间隔离保留。上号更新仍需下载后由用户点击安装并重启。
