# 上号 2.2.1

这一版扩展了游戏识别范围，并重点解决 KK 官方对战平台长期在后台运行时容易被误判
为正在游戏的问题。语音协议保持不变，可与 2.2.0 使用相同的服务器配置。

## KK 游戏识别

- KK 平台启动器、更新器和大厅进程不会单独触发“游戏中”。
- 只有实际游戏进程启动，并在窗口标题、安装路径或启动参数中出现可信证据时，才会
  更新成员状态和工位显示器。
- 新增《向魔兽开炮》《尸潮庇护所》、DotA 1、魔兽争霸 3、CS 1.6、红色警戒 2、
  拳皇 97 和星际争霸等常见内容。

## 更多常见游戏

新增穿越火线、地下城与勇士、魔兽世界、炉石传说、燕云十六声、鸣潮、绝区零、
暗区突围：无限、逃离塔科夫、极限竞速：地平线 5、赛博朋克 2077、巫师 3 和
战地风云等识别规则。没有专属封面的游戏会显示清晰的通用游戏图标和名称。

## 安装

上号 2.2.1 支持 Windows 10/11 x64。下载
`ShangHao-2.2.1-Setup-x64.exe` 后可以覆盖安装。安装后可先只打开 KK 大厅确认不会
显示“游戏中”，再启动具体地图，状态通常会在一个检测周期内更新。
