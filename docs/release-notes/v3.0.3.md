# 上号 ShangHao v3.0.3 更新公告

发布日期：2026-08-24

v3.0.3 是一次覆盖账号、AI 模型、录音转录、屏幕分享和房间反馈的完整体验更新。安装会保留现有设置、聊天、收藏、录音、模型目录与转录结果，不会把数 GB 模型放进安装包。

## 账号与永久身份

- 新增用户名、邮箱、密码注册与十套本地 SVG 默认头像，也支持上传自定义头像。
- 支持邮箱登录、Supabase 托管的用户名登录、重启自动登录、Session 刷新、退出登录、昵称和头像更新。
- Session 使用 Windows 安全存储加密；Refresh Token 不进入 Renderer、普通配置或日志。
- 房间服务器验证 Supabase Access Token 后取得真正 userId、用户名、昵称和头像，不直接相信客户端提交的 userId。
- 开发测试可继续连接现有 `ws://` 房间服务器，但只有短期 Access Token 会随房间连接发送；密码与 Refresh Token 始终只访问 Supabase 官方 HTTPS。
- `/api/account/status` 的旧服务 404、账号后端未配置与 TLS 未启用现在是三种不同诊断。

## 九套转录模型与统一 CUDA Runtime

- 保留 Qwen3-ASR 0.6B/1.7B、Qwen3 ForcedAligner、Fun-ASR-Nano、GLM-ASR-Nano、FireRedASR2-AED 与 Paraformer 中文套件。
- 新增 MOSS-Transcribe-Diarize 0.9B、Dolphin-CN-Dialect 0.4B 和 Cohere Transcribe 2B。
- GPU 模型统一复用 ShangHao 独立 AI Runtime；CUDA、PyTorch、GPU、显存、BF16/FP16 与 DLL 状态进入自检和诊断日志，不依赖系统 Python。
- Fun-ASR 按 `model.pt`、`config.yaml`、`configuration.json`、`multilingual.tiktoken` 校验；FireRed 正确认出 `model.pth.tar` 及官方配套文件。
- Cohere 是 Hugging Face 门控模型。模型卡会引导接受条款、创建只读 Token，并由 Windows 加密保存在本机；授权只发送给 `huggingface.co`。
- 下载、授权、完整性校验、Runtime 启动和磁盘错误分别显示；到达 100% 后会进入明确校验阶段，不再伪装成仍在下载。

## 录音与文字结果

- ForcedAligner 的字级时间戳继续保留为底层数据，界面按说话人、停顿、标点和最大句长合并为可读句段。
- 点击句段仍可跳到准确开始时间，AI 整理也使用合并后的句子，不再被逐字重复时间和说话人污染。
- 录音库模型选择与 AI 功能页完全同步；切换模型时会优先显示该模型已有结果。
- 暂停转录显示真实进度，录音响度平衡作为后台默认能力运行；保存成功改为顶部中央轻通知。

## 屏幕分享与房间体验

- 增加固定 1440p 分享，动态内容提升到适合视频和游戏的帧率，不使用隐藏画质档位或自动降级。
- 分享者可看见正在观看的成员；无人观看一段时间后自动停止，避免持续占用上行带宽。
- 共享画面、独立观看窗口、问答和更新弹窗使用一致的玻璃模糊与清晰文字背景。
- 更新退出显示“正在更新”，异常重连显示“正在回来”，手动退出直接移除成员。
- 修复扬声器/麦克风菜单无法打开、说话时角色位置跳动、录音状态夹在布局缝隙、日历比例和房间边缘填色等问题。

## 动效、天气与声音

- 恢复并扩展天气环境光、昼夜色温、窗户细节、角色接触阴影、说话能量、错峰待机动作和状态仪式。
- 设置、弹窗、更新、下载、录音和屏幕分享增加一致的进入/退出、完成与错误反馈。
- 扩展界面音效，统一响度并降低开麦等高频操作音量；装饰反馈不会替代清晰的文字状态。

正式安装包：`ShangHao-3.0.3-Setup-x64.exe`
