# 上号 ShangHao v3.0.3 综合更新公告

发布日期：2026-08-24

本版本已汇总整合 v3.0.2 更新与 v3.0.1 本地开发成果；功能按主题去重归类，安装包与代表性截图统一保留在本页。

这是一次覆盖账号身份、房间性能、AI 转录、录音回顾、屏幕分享与界面反馈的综合更新。安装或更新会保留现有设置、聊天、收藏、录音、模型目录与转录结果；数 GB 的 AI 模型继续由用户按需下载，不会放进安装包。

## 账号与永久身份

- 支持用户名、邮箱和密码注册、邮箱登录、Supabase 托管的用户名登录、重启后恢复登录、Session 刷新、主动退出以及昵称和头像更新。
- 提供十套本地 SVG 默认头像，也支持上传自定义头像。
- Session 使用 Windows 安全存储加密；Refresh Token 不进入 Renderer、普通配置或日志。房间服务器验证 Supabase Access Token 后取得真实用户身份，不直接信任客户端提交的 userId。
- 旧账号服务 404、账号后端未配置与 TLS 未启用会显示为不同诊断状态。开发测试仍可连接既有 `ws://` 房间服务器，但密码与 Refresh Token 始终只通过 Supabase 官方 HTTPS 传输。

## 房间性能与实时语音

- 角色换座使用 transform 动画层，不再由 React 在每个显示帧驱动位置；角色静止时停用头、身体与尾巴的空闲循环，`will-change` 只在行走期间启用。
- 语音活动分析固定约 30Hz；麦克风保护、VAD、回声证据与混音改用 AudioWorklet 音频时钟，避免跟随 120/144Hz 显示刷新率重复工作。
- 修复静音成员的已建立 WebRTC 连接因短时没有音频而被周期性重建的问题。旧房间会话被替代后，会清理计时器、Peer、音频回退与屏幕分享资源。
- RoomPage 与状态订阅保持细粒度更新；屏幕分享兜底帧采用去重、合并和 single-flight，分离窗口不再逐帧发送 IPC。
- 保留说话、游戏和交互动画，以及五人语音、WebRTC Mesh、ICE/TURN/Relay、AEC、DeepFilter、VAD、双讲、人声保护与好友独立音量等既有能力。

## 录音、转录与 AI 整理

- 转录与文字整理可分开执行，也可分别开启自动处理。整理失败不会丢失已经成功的原始转录；音频转换、模型启动、识别、整理与保存失败会显示对应阶段和原因。
- 字级时间戳保留为底层数据，界面按说话人、停顿、标点和句长合并为可读句段；点击句段仍跳到对应音频位置，AI 整理使用合并后的句子。
- 支持九套可选 ASR 方案：Qwen3-ASR 0.6B/1.7B 与共用 ForcedAligner、Fun-ASR-Nano、GLM-ASR-Nano、FireRedASR2-AED、Paraformer 中文套件、MOSS-Transcribe-Diarize、Dolphin-CN-Dialect 与 Cohere Transcribe。转录模型与文字整理模型分层设置，模型切换不会改写历史转录所用的模型记录。
- GPU 模型复用 ShangHao 独立 AI Runtime；CUDA、PyTorch、GPU、显存、BF16/FP16 与 DLL 状态进入自检。Fun-ASR、FireRed 等模型按官方权重及配套配置校验。Cohere 属于 Hugging Face 门控模型，接受条款后可使用只读 Token，并由 Windows 加密保存在本机。
- 暂停转录每 30 秒保存断点；继续处理已完成片段之后的内容，只有重新转录才清除旧断点。暂停显示实际进度，低优先级 AI 任务会在语音房、屏幕分享或连接恢复繁忙时让路。
- 房间问答与文本整理可选房间云端、本地 Qwen 或自定义 OpenAI 兼容 API。问答支持停止生成；关闭浮窗会取消本地或云端任务。密钥留在服务端环境或 Windows 加密存储，不进入客户端日志或 GitHub。

## 录音库、模型诊断与游戏场景

- 优化设置页、录音库工具栏和播放区，让录音列表与转录内容更易查看；长转录可返回顶部，录制时间、时长和文件占用使用明确中文标签。
- 清理录音优先处理短录音、静音和损坏文件；容量仍超限时再处理较旧录音，收藏和带标记录音继续受到保护。
- AI 诊断用中文展示模型、状态、最近文件、处理阶段和失败原因。录音响度平衡作为后台能力运行，保存成功使用轻通知反馈。
- 星露谷物语、英雄联盟与三角洲行动使用各自的小屏工位画面；相关视觉资源按统一构图和低开销规则呈现。

## 屏幕分享与房间交互

- 增加固定 1440p 分享；动态内容使用适合视频和游戏的帧率，不通过隐藏画质档位或自动降级掩盖问题。
- 分享者可以查看正在观看的成员；一段时间无人观看后自动停止分享，减少不必要的上行占用。
- 更新退出显示“正在更新”，异常重连显示“正在回来”，主动退出会立即移除成员。共享画面、独立观看窗口、问答和更新弹窗使用一致的清晰文字背景。

## 启动完整性与本地数据

- 修复首批 v3.0.2 安装包中 Qwen runner 与 AI Runtime 清单 SHA256 不一致、导致更新后出现 `ai_runtime_integrity_failed` 的问题；打包前后重新计算 runner 哈希，清单过期会让检查失败。
- 移除未经校验覆盖 Qwen runner 的路径。AI Runtime 缺失或损坏时，主客户端、语音房、聊天和录音仍可启动，并在 AI 页面说明实际错误。
- 安装与更新不清理本地设置、模型、录音、转录文字、聊天记录、收藏或 Marker。AI Runtime 与大型模型按需下载，不放进安装包。

## 画面、天气与声音反馈

- 恢复并扩展天气环境光、昼夜色温、窗户细节、角色接触阴影、说话能量、错峰待机动作与状态反馈。
- 设置、弹窗、更新、下载、录音和屏幕分享使用一致的进入、退出、完成与错误反馈；界面音效统一响度并降低开麦等高频操作音量。装饰性反馈不会替代清晰的文字状态。
- 修复扬声器/麦克风菜单无法打开、角色换座时位置跳动、录音状态布局错位、日历比例与房间边缘填色等问题。
