# 上号 ShangHao v3.0.2 更新公告

发布日期：2026-08-22

v3.0.2 是一次性能稳定与本地语音记忆修复版本。它完整承接尚未发布到远端的 3.0.1 本地开发成果，重点处理进房、换座、设置切换和后台空闲时的卡顿，同时把录音转文字、文字整理、失败重试和诊断提示整理成可独立运行的完整链路。

## 房间性能与实时连接

- 角色换座使用浏览器合成层动画，角色不移动时停止多余的空闲叠层循环；装饰和工位屏幕也会在关键交互期间主动降载。
- 修复已建立 WebRTC 连接的静音成员因为暂时没有音频而被周期性重建的问题，减少后台 ICE、信令和 Peer 抖动。
- 旧房间会话被新会话替代后会停止计时器、Peer、音频回退和屏幕分享资源，避免重复客户端留在后台。
- 屏幕分享兜底帧去重、合并和节流，RoomPage 与 Zustand 订阅继续保持细粒度更新。

## 录音转录与 AI 整理

- 转录和整理拆成两个独立按钮，也可以分别开启自动处理；已经转录成功的文字不会因为整理失败而丢失。
- 录音会先转换成 ASR 需要的标准音频，转换、模型启动、识别、整理和保存任一步失败都会显示对应阶段与真实原因。
- 支持在 VibeVoice-ASR-BitNet、Qwen3-ASR-0.6B、Paraformer-zh + FSMN-VAD + CT-punc 三套 ASR 方案之间下载和切换；转录模型与 Qwen 整理模型保持分层。
- 后台 AI 任务采用低优先级队列，语音房、屏幕分享或连接恢复繁忙时会避让，避免阻塞主进程和房间界面。

## 录音库与设置界面

- 压缩设置页顶部、录音库工具栏和播放控制所占空间，让录音列表与转录文字成为主要内容。
- 播放、进度和倍速区域保持可见，长转录支持一键返回顶部；录制时间、录音时长和文件占用使用明确中文标签。
- 清理录音先处理短录音、静音和损坏文件；容量仍超限时再处理最旧录音，并继续保护收藏和带标记录音。
- AI 运行诊断改为可读中文，保留模型、状态、最近文件、处理阶段和失败原因，不再向普通界面暴露内部任务字符串。

## 图标与游戏工位屏幕

- 修复开发环境中部分应用图标回退异常。
- 星露谷物语、英雄联盟和三角洲行动使用独立的小屏工位画面，统一构图、可读性和低开销呈现规则。

## 兼容与数据

- 保留五人语音、后加入音频、WebRTC Mesh、ICE/TURN/Relay、AEC、DeepFilter、VAD、双讲、人声保护、好友独立音量、聊天、屏幕分享、自动录音和 Marker 等现有能力。
- 安装或更新不会把本地 AI 模型、录音、转录文字、聊天记录、收藏和用户设置打进发布包，也不会主动删除这些本地数据。

正式安装包：`ShangHao-3.0.2-Setup-x64.exe`
