# 上号 ShangHao v3.0.2 更新公告

发布日期：2026-08-22（同版本修正版已重新发布）

v3.0.2 是一次性能稳定与语音记忆修复版本。它完整承接尚未发布到远端的 3.0.1 本地开发成果，重点处理进房、换座、设置切换和后台空闲时的卡顿，同时把录音转文字、文字整理、失败重试和诊断提示整理成可独立运行的完整链路。

## 房间性能与实时连接

- 角色换座使用 transform-only 合成层关键帧，不再由 React 在每个显示帧驱动位置；只有移动被打断时才读取一次当前位置。
- 角色不移动时停止头、身体和尾巴等多层空闲循环，`will-change` 只在实际行走期间启用；保留说话、游戏和交互动画。
- 语音活动分析从跟随 120/144Hz 显示刷新率改为固定约 30Hz；麦克风保护、VAD、回声证据与混音改用 AudioWorklet 音频时钟。
- 修复已建立 WebRTC 连接的静音成员因为暂时没有音频而被周期性重建的问题，减少后台 ICE、信令和 Peer 抖动。
- 旧房间会话被新会话替代后会停止计时器、Peer、音频回退和屏幕分享资源，避免重复客户端留在后台。
- 屏幕分享兜底帧去重、合并和 single-flight，RoomPage 与 Zustand 订阅保持细粒度更新，分离窗口不再按每一帧发送 IPC。
- 本次没有用动态模糊掩盖掉帧；详细根因、代码路径和回归清单见 [3.0.2 性能与启动故障参考](../stabilization-reference-3.0.2.md)。

## 同版本修正版：启动完整性

- 修复首批 3.0.2 安装包中 `qwen-runner.py` 与 AI runtime 清单 SHA256 不一致，导致更新后提示 `ai_runtime_integrity_failed` 的问题。
- 打包前与打包后都会重新计算 runner 哈希，清单过期会直接让测试或发布失败。
- AI 是可选后台能力；即使 AI runtime 损坏或缺失，主客户端、语音房、聊天和录音仍可启动，AI 页面会保留真实错误。
- 移除通过未校验复制再次覆盖 Qwen runner 的路径；不删除设置、录音、模型、聊天或已有转录。

## 录音转录与 AI 整理

- 转录和整理拆成两个独立按钮，也可以分别开启自动处理；已经转录成功的文字不会因为整理失败而丢失。
- 录音会先转换成 ASR 需要的标准音频，转换、模型启动、识别、整理和保存任一步失败都会显示对应阶段与真实原因。
- 支持六套官方 ASR 方案独立下载和切换：Qwen3-ASR 1.7B/0.6B + 共用 ForcedAligner、Fun-ASR-Nano、GLM-ASR-Nano、FireRedASR2-AED，以及 Paraformer + FSMN-VAD + CT-Punc；转录模型与文字整理模型保持分层。
- 暂停转录会保留每 30 秒落盘的断点，“继续转录”从已完成片段后接着处理；只有“重新转录”才会清空旧断点。
- 修复 Paraformer 中文套件漏装 `torchaudio` 导致 worker 启动失败；修复组件会按内置 PyTorch 版本和 CUDA 变体安装匹配的运行依赖。
- 整理内容和房间“问”可以分别选择房间云端、本地 Qwen 或用户自己的 OpenAI 兼容 API；房间云端为默认选项，问答支持服务端联网搜索。
- 房间云端密钥只存在自托管 Relay 的环境变量中；自定义 API 密钥由 Windows 加密后只保存在本机，均不会进入客户端设置、日志或 GitHub。
- 每条转录会保存并显示实际使用的 ASR 模型，切换当前模型不会改写历史标注，便于长期比较六套模型的识别效果；无法可靠追溯的旧记录会明确显示“模型未知”。
- 房间“问”在生成回答期间会显示“停止回答”；点击或关闭提问浮窗会立即取消本地模型、自定义 API 或房间云端任务，云端服务器也会同步终止上游请求，不再一直占用电脑或连接直到超时。
- 后台 AI 任务采用低优先级队列，语音房、屏幕分享或连接恢复繁忙时会避让，避免阻塞主进程和房间界面。

## 录音库与设置界面

- 压缩设置页顶部、录音库工具栏和播放控制所占空间，让录音列表与转录文字成为主要内容。
- 播放、进度和倍速区域保持可见，长转录支持一键返回顶部；录制时间、录音时长和文件占用使用明确中文标签。
- 清理录音先处理短录音、静音和损坏文件；容量仍超限时再处理最旧录音，并继续保护收藏和带标记录音。
- AI 运行诊断改为可读中文，保留模型、状态、最近文件、处理阶段和失败原因，不再向普通界面暴露内部任务字符串。

## 图标与游戏工位屏幕

- 修复开发环境中部分应用图标回退异常。
- 星露谷物语、英雄联盟和三角洲行动使用独立的小屏工位画面，统一构图、可读性和低开销呈现规则。

## 兼容与数据

- 保留五人语音、后加入音频、WebRTC Mesh、ICE/TURN/Relay、AEC、DeepFilter、VAD、双讲、人声保护、好友独立音量、聊天、屏幕分享、自动录音和 Marker 等现有能力。
- 安装或更新不会把本地 AI 模型、录音、转录文字、聊天记录、收藏和用户设置打进发布包，也不会主动删除这些本地数据。

正式安装包：`ShangHao-3.0.2-Setup-x64.exe`
