# 上号 ShangHao v3.0.6 更新公告

> 这次更新，重点是把账号、进房和日常使用体验继续收稳。该修的卡顿、错位和不清楚的提示，尽量都变成了用户能直接感受到的改进。

## 这次最值得注意的变化

- **账号系统更顺了**：注册、登录、手机号验证码、CloudBase Session 和房间身份统一走 CloudBase，重新打开软件也能保持登录状态。
- **进房更可靠**：客户端与频道服务器的协议不匹配时会直接给出明确提示，不再等很久只显示“没有确认加入频道”。
- **角色状态更完整**：角色平时会显示 **“等待中”**，说话时切换为 **“正在说话”**，静音、游戏和离开状态仍会显示各自状态。
- **图片预览更丝滑**：大图会在展开动画前完成解码，减少打开和缩放时突然掉帧的情况。
- **房间控制更轻**：打开麦克风或扬声器菜单不会再牵连整个房间场景重渲染，角色进场路线也不会因短暂连接状态变化而退回重走。
- **手机号更不容易填错**：注册页自动显示 `+86`，用户只输入普通 11 位手机号即可；粘贴带区号的号码也会自动整理。

## 还有一些小但重要的整理

- 账号错误提示、验证码提示和网络错误提示进一步区分，遇到问题时更容易知道下一步该做什么。
- 官网下载页会优先使用腾讯云镜像，GitHub Release 作为备用下载地址，并显示当前正式版本。
- 保留原有房间、语音、WebRTC、录音和 AI 功能，不改变既有模型和音频工作流。
