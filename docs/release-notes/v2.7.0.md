# 上号 v2.7.0

> 本文件是本地开发说明。v2.7.0 当前没有推送、打包、发布或部署。

## 还是现在这套上号

v2.7.0 更新的是运行环境和长期维护基础，不重新设计界面、不减少功能、不删除动画。
房间、五个工位、小动物、聊天、设置、录音库、昨日房间、更新中心、AI 语音记忆和悬浮窗
继续保持当前本地版本的操作方式。

## 更新了什么

1. 桌面运行环境升级到 Electron 42，继续支持主窗口、托盘、悬浮窗、深链、开机启动、
   WebRTC、屏幕分享、AudioWorklet、DeepFilter 和自动更新。
2. 界面运行环境升级到 React 19.2，构建工具升级到 Vite 8 和 Tailwind CSS 4；现有 UI、
   字体、配色、布局和动画全部保留。
3. TypeScript 使用成熟稳定的 5.9，并升级 WebSocket、版本判断、构建和开发工具依赖。
4. Windows 打包继续使用 NSIS，electron-builder 与 electron-updater 升级到维护版本。
5. 覆盖安装新增 `.shanghao-install-manifest` 清单，只清理上号自己安装的文件；用户放入
   安装目录的其它文件不会被递归删除。
6. 没有清单的旧版仍可直接覆盖升级；AppData、录音目录和本地 AI 模型与程序安装目录分离，
   不会随程序更新被清理。
7. GitHub Actions 升级并继续执行 Windows 构建、类型检查、测试和五人语音验证；Dependabot
   将 Electron、React 和构建工具分组维护，重大版本仍由人工处理。

## 本地开发状态

- 协议版本继续为 7。
- 生产服务器的 `requiredClientVersion` 没有修改。
- 当前阶段不推送 GitHub、不创建 Release、不上传安装包、不部署服务器。
