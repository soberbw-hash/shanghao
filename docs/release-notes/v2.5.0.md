# 上号 2.5.0

这一版不改变固定服务器方向，也没有重写已经验证稳定的五人语音核心。重点是把切房、
屏幕分享、聊天撤回和 Windows 覆盖安装做成不会互相抢状态的完整流程。

## 切房不再留下旧房间

- 在一号房和二号房之间切换时，上号会先完成旧房间收尾，再进入新房间。快速连续点击
  不会同时发起多次加入，也不会重复占用角色。
- 仍在加载的屏幕分享来源会被取消；本地分享 Track、独立观看窗口、远端画面、聊天和
  珍藏快照都会随旧房间清理，避免新房间看到旧内容。
- 顶部去掉重复且容易抖动的说话文字。谁正在说话仍会在角色和悬浮窗中用统一状态显示。

## 屏幕分享更容易恢复

- 显示器和应用窗口继续使用系统来源列表与 1440p 质量，并可选择是否分享系统声音。
- 点击取消后，仍在后台返回的旧来源不会把选择窗口重新打开；枚举失败后可以直接重试。
- 停止、退出和切房会立即停止采集，再异步通知房间；即使网络收尾失败，本机也不会留下
  亮着的分享状态或继续采集的窗口。

## 五人语音与说话状态

- 完整保留五人共享混音器、真实可播放 PCM 证明、隐藏解码泵和逐成员语音兜底。第四、
  第五位好友晚加入时，既有成员的声音仍会继续验证后再切换播放路径。
- 说话状态会继续学习持续的低强度底噪。风扇、声卡底噪或虚拟麦克风不会因为一次误触发
  就一直显示绿色；真正说话时，房间角色和悬浮窗同步变化。
- 每位好友的 0–200% 本地音量和仅本机静音保持不变，不会修改对方麦克风。

## 聊天与设置

- 自己发送的消息现在可以撤回。撤回由服务器确认作者后同步到房间内所有在线客户端，
  同时从服务器聊天历史删除，后来进入房间的人也不会再看到。
- 链接安全交给系统默认浏览器打开；图片继续支持桌面拖入和剪贴板粘贴，发送前压缩、
  统一缩略图显示，点击可查看清晰大图。长文字和超长链接不会撑破聊天布局。
- 首页增加自动增益开关，与设置页即时同步。设置页保留最近 10 个版本，默认展开最近
  4 个版本，也可以点击任意版本查看具体变化。

## 安装更新更安全

- 上号安装目录现在带有专属标记，覆盖安装前必须验证固定标记内容。旧版升级只在主程序、
  应用资源和卸载器同时存在时迁移标记，单独一个同名 EXE 不足以获得清理权限。
- 安装器不再递归删除整个自定义安装目录，只移除明确属于上号和 Electron 的已知文件。
  如果目录身份不明确，安装器会停止并提示更换为单独的上号目录。

## 升级说明

客户端与固定服务器的协议版本已更新到 7。请先更新固定服务器，再让所有好友安装
`ShangHao-2.5.0-Setup-x64.exe`，避免新旧客户端混用。
