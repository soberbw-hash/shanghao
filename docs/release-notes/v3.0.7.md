# 上号 ShangHao v3.0.7 更新公告

> 这次不堆新按钮，专门收拾那些“看着不大、用着膈应”的问题：音乐播一半没了、鼠标侧键装没听见、切页面先愣一下、图片一打开还闪白。

## 🎵 音乐这次会把整首唱完

- **长 AAC 不再中途断掉**：快捷音乐改为完整文件与 Range 分段流式读取，播放器需要续读时可以从正确位置继续。
- **你的原始音乐一刀没动**：13 首音乐与提供的源文件逐一核对，文件大小和 SHA-256 完全一致，没有再次裁切。
- **自己和好友走同一条稳定播放链路**：快捷栏点击、房间同步和快捷键触发都读取同一份内置完整音频。

## 🖱️ Mouse4 / Mouse5 不再装死

- **只有快捷键真的改了才重注册**：拖音量、换预览音乐等操作不会再高频拆掉侧键监听。
- **八个槽位按顺序注册**：避免多个保存任务同时争用同一个原生鼠标 Hook。
- **相同配置直接复用**：已经生效的侧键不会被无意义地移除再创建。

## ✨ 丝滑，但不牺牲原来的好看

- **设置页提前准备**：录音库、AI 等重页面在浏览器空闲时渐进预热，访问后继续保留，不用每次重新搭一遍界面。
- **图片不再白闪**：未解码的图片首帧保持透明，准备好后再接上原有的空间展开动画。
- **揪出一层误伤性能的全屏滤镜**：图片透明画布不再误套小弹窗的 24px 模糊；图片阴影、圆角、暗色遮罩、动画以及软件其他玻璃模糊全部保留。
- **音频菜单首次打开更稳**：麦克风和扬声器面板在动画期间按需使用合成层，动画结束后自动释放。

## 🔐 新包必须真的能登录

- 正式 Windows 构建会注入 CloudBase 环境、区域和 Publishable Key。
- 打包后会再次检查 `app.asar`；如果登录配置没真正进入安装包，发布流程会直接失败，不允许再把“账号服务尚未配置”的包发出去。

## 🌐 官网与下载

- “关于上号 → 作者与项目”增加紧凑的 **官方网站** 入口。
- GitHub Release、Windows x64 EXE、自动更新文件、官网版本信息和 CloudBase 下载镜像同步更新为 **3.0.7**。
