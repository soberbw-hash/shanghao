# 上号 ShangHao v3.1.0 更新公告

这版是一次多人房间体验与底层流畅性收口版本。重点解决多人同时入座时的成员可见性、账号头像同步和快捷语音入口问题，同时把已经完成的启动与渲染性能优化整理成可发布的 Windows 版本。它不改变五人实时语音、录音、屏幕分享或信令协议边界。

## 👥 多人房间与账号同步

- 修复座位上的人偶发显示不全的问题：房间成员列表按服务端状态保持完整，后加入成员也能稳定出现在正确座位。
- 左侧房间悬浮窗显示每个账号自己的头像、昵称和在线状态；头像来自账号资料，并通过服务器同步更新，不再错误显示“我”或首字母占位。
- 聊天消息旁继续使用对应账号头像，角色状态栏只展示昵称、延迟和当前状态，不混入头像。

## 🎛️ 快捷语音入口

- 聊天区域右上角设置按钮保持与“聊天”标题同行、右对齐并保留边距。
- 点击该按钮直接跳转到设置页的快捷语音页面，快捷消息、音乐和快捷键可以在同一处管理。

## ⚡ 流畅性与启动稳定

- 对设置页聊天和运行状态更新做边界控制，避免无界的 DOM 更新在频繁切换时拖慢界面。
- AI 服务改为延后启动，把启动阶段的资源优先分配给房间、语音、信令和用户可见交互。
- 完成 Electron 42.11.5 运行时校验，并保留现有平台能力边界与数据兼容策略。

## ✅ 验证与自动更新

- 发布前执行 TypeScript、Lint、生产构建、桌面运行时验证以及 Windows 10/11 x64 安装包检查。
- Windows Release 保留安装器、`latest.yml`、`.blockmap` 与 `SHA256SUMS.txt`，供 electron-updater 和人工校验使用。
- 官网下载页从 GitHub 最新正式 Release 读取版本，安装包镜像只在校验 SHA-256 和文件大小后激活。

本版本没有修改五人 WebRTC、音频处理、录音、屏幕分享、信令协议或用户本地数据格式。自动化验证不等同于真实多设备听感、公网 TURN 和不同硬件的最终验收。
