# 上号 2.3.0

这一版集中收口五人语音、入场设备检查、屏幕分享来源、角色动画和房间长期使用体验。
固定服务器地址与连接协议保持不变，所有参与者建议统一升级后再进行多人测试。

## 五人语音与连接恢复

- 五个独立 Electron 客户端验证全部 20 条成员到成员的可解码音频方向，并覆盖
  第五人晚加入、单成员链路销毁和双向恢复。
- 远端成员共享同一个音频混音器，减少多人房间中的 AudioContext 数量和设备切换故障。
- 同一资料重新连接时会原子清理旧会话、旧角色和旧音频路由，避免重开软件后残留
  “幽灵成员”占用位置。

## 设备、人声与屏幕分享

- 首页可直接选择麦克风和扬声器；进入频道前会真实打开所选输入设备，并验证所选
  输出设备能够建立播放链路，兼容 RODE Connect 等虚拟音频设备。
- DeepFilterNet 继续作为唯一降噪引擎，设置页新增默认开启的人声增强，并移除固定
  输入阈值与无操作价值的说明卡。
- 屏幕分享来源枚举增加内容保护切换和重试，缩略图不可用时仍显示可选窗口，分享流
  建立后自动恢复窗口保护，固定使用 1440p。

## 动画、悬浮窗与珍藏

- 角色进入、换座和离开统一为可打断动画事务；快速切换时会从当前视觉位置继续，
  不再出现坐姿漂移、抽搐或旧动画把角色拉回去。
- 悬浮窗改为左侧纵向成员列表，用头像光效直观区分说话、静音和空闲。
- 新增“频道珍藏”，支持短文字、链接和图片地址，并持久保存在服务器的房间数据中。

## 安装与验收

上号 2.3.0 支持 Windows 10/11 x64。请安装
`ShangHao-2.3.0-Setup-x64.exe`，并优先完成两台真实电脑、四人和五人房间、断线重连、
音频设备切换与屏幕分享验收。
