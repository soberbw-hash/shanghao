# 上号 ShangHao v3.0.10 更新公告

这版是一次房间视觉升级：把参考图里的空间、光影、天气和层级关系真正落到可维护的界面组件里，同时把头像、聊天设置和找回密码流程补齐。

## 🎨 房间视觉升级

- 重绘窗外晴天、阴天、雨天、雪天和夜景，并接入动态云、雨、雪、雾、闪电和环境光；页面不可见或用户开启减少动效时，纯视觉动画会按规则暂停。
- 五个工位、门、书架、窗帘和前景叶子重新整理位置与层级；窗帘从房间顶部垂下，左下前景叶子自然遮住门角，组件阴影与室内光线保持融合。
- 日历改为保留立体材质的空白底图，由界面绘制实时日期，去除“贴白纸”的矩形覆盖感；同时补足日历、闹钟等组件的落影。
- 桌面环境亮度继续压低以融入背景，但电脑实时屏幕保持正常亮度；修正四、五号位屏幕边缘的细黑线。
- 悬停座位时只显示当前座位数字，数字位于角色后方，不再盖住角色；角色状态栏移动到角色下方，避免挡住后排电脑。

## 🐾 角色、账号与聊天

- 角色状态栏只显示昵称、延迟和当前状态，不显示头像。
- 聊天消息旁显示账号头像；本机历史消息也会优先使用当前账号头像和昵称，不再错误显示“我”或仅显示首字母占位。
- 聊天设置按钮固定在“聊天”标题行右侧，并保留小幅右侧留白。

## 🔐 找回密码

- 忘记密码流程补齐验证码输入框、新密码、确认新密码和提交步骤。
- 保留验证码重发倒计时、过期、格式错误、两次密码不一致等提示，不会把“发送验证码”当作完成流程。

## ✅ 验证与发布资产

- Windows 10/11 x64 NSIS 安装包。
- 自动更新文件：`latest.yml`、`.blockmap` 和 `SHA256SUMS.txt`。
- 本地 TypeScript、Lint、桌面测试、Native、五端音频/媒体、生产构建和安装包验收由发布流程执行；视觉回归预览覆盖动态天气、日历、窗帘、前景遮挡、工位屏幕、角色层级、聊天头像和设置入口。

本次没有改变五人 WebRTC、音频处理、录音和信令协议边界。自动化测试通过不等同于真实多设备听感、公网 TURN 和不同显卡的硬件验收。
