# 上号 3.4.5

查找更清楚，操作更顺手。

## 本次更新

- **独立查找房间。** 点击“查找”打开毛玻璃弹窗；找到后隐藏频道号输入，只显示房间与加入按钮。
- **数字输入更自然。** 验证码和频道号各自在原入口使用逐格输入、检查和完成动效，支持粘贴、前导零及单格修改。
- **界面音量可调。** 设置切换与普通按钮使用统一点击音；通用新增“界面音效音量”，语音包音量独立保留。
- **回座与退出更稳。** 改善手动回座后被迟到状态送回门口的问题，保留座位冲突处理；长录音退出时提示正在保存，完成后再返回首页。

## 稳定性补充

- 已有每日回顾先显示，文案后台补充；再次打开可读取新内容。
- 云端备用增加有界排队，回顾与自动记忆采用统一总超时；保留取消及限速冷却。
- 修正动画队列遗漏，限制云端响应正文大小。
- 开发版热更新保留房间运行时引用，快捷消息失败提示更具体。

用户的录音、聊天、设置、模型与历史资源保留。更新仍需下载完成后由用户点击安装；自动化验证不代替真实设备听感与旧版升级实测。
