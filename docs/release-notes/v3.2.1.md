# 上号 ShangHao v3.2.1 更新公告

这一版把近期的设置、聊天和房间画面调整收在一起，也继续收紧启动、诊断与更新流程。Windows 10/11 x64 是正式支持平台。

## 设置用起来更顺手

- “我的快捷消息”合并语音／音效与音乐槽位，音频库里可以拖拽绑定、试听，并调整播放开关和音量。音频包条目更紧凑，后续添加更多内容时更容易浏览。
- AI 模型列表移除多余搜索和留白，筛选靠近标题；模型操作菜单不再被邻近卡片遮住。GLM-ASR-Nano-2512 显示“默认推荐”，只影响新配置，已有选择保持不变。
- 登录页删除重复说明，声音检测移到卡片右上区域。房间记录移除不必要的搜索，Windows 外观实验选项直接展示。

## 聊天、手机麦克风与房间画面

- 聊天链接卡片在可获取时显示网页标题和缩略图；获取不到时仍保留可点击的链接卡片。
- Android USB 手机麦克风未插入、未开启调试或尚未授权时，界面给出原因和下一步操作，不展示底层 IPC 异常文字。
- 调整角色静坐时头部与身体的同步运动；夜间天气、窗帘、小草和角落装饰增加轻微变化。纯视觉运动遵循页面可见性和减少动态效果设置。

## 稳定性与验收边界

本次继续保护五人语音、后加入成员音频、房间隔离、聊天确认与重试、录音以及用户本地资料。诊断只使用有界运行统计，不采集聊天或转录正文、音频内容。更新在后台下载，安装并重启仍需要用户主动点击。

自动化构建和五端回归只验证代码路径。旧版已安装客户端实际走完“发现更新 → 下载完成 → 点击安装并重启”，以及好友在另一台设备上听到手机麦克风，都需要分别实机验收。
