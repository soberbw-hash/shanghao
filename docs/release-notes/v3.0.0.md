# 上号 ShangHao v3.0.0 更新公告

发布日期：2026 年 8 月 20 日

v3.0.0 是在 v2.9.x 本地综合开发基线之上的正式整合版本。它把已经验证的房间、语音、屏幕分享、录音和本地 AI 能力整理到清晰的 Core/Platform/Visual Runtime 边界，同时继续优先保护五人实时语音和用户本地数据。

## 3.0 架构整理

- Renderer 通过显式、类型化的 `shanghaoCore.*` 能力访问桌面能力，避免万能 IPC 通道。
- Windows 平台能力集中在 PlatformService；Rust Core 只承担前台活动、稳定文件身份和受控 AI 子进程监督。
- VisualRuntimeController、RoomAnimationScheduler 和可见性策略统一管理房间视觉资源，页面隐藏时暂停纯视觉循环，不暂停音频、信令、录音或 WebRTC。
- 诊断页面补充实时帧率、屏幕分享链路、WebRTC、音频处理和 Windows 网络权限信息。

## 房间与角色

- 角色卡的昵称、延迟和状态文字使用固定对齐槽位，切换麦克风或扬声器状态不会再出现文字左右跳动。
- 状态框整体收紧，常用状态完整显示；KK 相关游戏统一显示“KK 对战平台”，不再展示具体游戏名称或英雄三国图标。
- 房间切换、离开、换座、晚加入和人物资源加载继续使用可恢复状态机，避免空座位闪烁或角色突然消失。
- 保留简洁今日挂历、天气、时钟、空闲工位屏幕、悬浮窗和一号房/二号房隔离。

## 语音、屏幕分享与录音

- 保持五人 WebRTC Mesh、按成员 ICE recovery、TURN 和 Relay 回退；远端音频仍由本地混音器输出。
- 保持 AEC、DeepFilterNet、VAD、Double Talk、人声保护、逐好友音量和默认开启的好友响度匹配。
- 屏幕分享继续使用统一采集服务和独立观看窗口，放大时优先保留原始清晰度并避免把缩略图强行拉伸。
- 录音库支持自动/手动录音、Marker、批量选择删除、失败重转和“清理录音”；清理会保护收藏和带 Marker 的文件。

## 本地 AI 与数据安全

- VibeVoice/Qwen Runtime、模型下载、暂停/继续、任务检查点和质量门禁继续由本机管理。
- 转录失败会保留明确失败原因并支持从头重试；乱码、无可靠人声和异常重复结果不会冒充成功内容。
- 覆盖升级不删除设置、聊天、收藏、录音、Marker、转录数据或用户已经下载的模型。

## 安装与验证

正式安装包：`ShangHao-3.0.0-Setup-x64.exe`

首次使用前请核对 GitHub Release 中的 SHA256SUMS，并在 Windows 防火墙提示时允许 ShangHao 的网络通信。详细架构、部署和开发说明见 [README](../../README.md) 与 [docs/architecture.md](../architecture.md)。
