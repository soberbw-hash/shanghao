# 上号 2.6.0

这一版把经常使用的录音、聊天和房间回顾做成了完整功能，同时继续保留已经验证过的五人
语音核心、固定服务器方向和五工位结构。

## 录音会自动回到录音库

- “自动录音并保存”默认开启。进入频道后自动开始，离开时直接保存，不再弹出确认窗口。
- 设置 → 录音库可以直接播放录音、拖动进度、查看标记点、切换倍速并播放下一条。
- 录音按“上号-一号房/二号房-日期-时间”命名；可以更改目录、打开文件夹和删除单条录音。
- 空间上限默认 5 GB，可自行调整。超过上限后从最旧录音开始清理，最新一条不会被刚录完就删除。

## 昨日房间留下一点生活痕迹

- 进入频道后，如果昨天有人来过，会看到一次简短的“昨日房间”。它不会延迟语音连接，
  也不会插入聊天消息。
- 刚更新软件时，会先显示版本更新说明；关闭动画结束后才显示昨日房间，两个弹窗不会重叠。
- 设置 → 房间记录可以分别查看一号房和二号房最近 14 个完整自然日。没人来的日期也会保留
  一行安静记录，但不会在进房时自动打扰。
- 只记录房间发生过什么：来过的朋友、房间亮起时长、最高在线、消息、屏幕分享、游戏和
  最后离开时间。不会统计谁说得多、静音时长、排行或聊天内容分析。

## 聊天与本地声音更顺手

- 同一位好友在短时间内连续发送的消息会自动分组，聊天列表更安静。
- 文字、图片和链接都可以右键直接复制；完成后显示统一的轻量提示。
- 每位好友的声音仍可单独调节 0–300% 或仅在本机静音。100% 位置有明确节点，拖动更容易
  回到正常音量，不会改变对方麦克风。

## 房间画面精修

- 背景调整为更干净的冷白和浅冰蓝，减少中央绿色雾感，并移除浅色网格。
- 桌子从曝光白改为有层次的浅白，降低高光和发光，桌腿与桌面之间更清楚，阴影更落地。
- 坐下角色放大并靠近工位，允许脑袋轻微压住桌子边缘；鸭子和椅子重新对齐。
- 名字框内部重新分配空间，选中工位的蓝色区域更淡，边线不再穿过角色。
- 底栏按钮的悬停、阴影和状态色统一：蓝色表示开启，绿色表示健康，红色表示录音、错误或危险操作。

## 邀请链接和升级说明

- 邀请链接会使用 `shanghao://` 打开上号并进入指定房间；开发环境会主动修复曾经写错的
  Windows 协议注册参数。
- 客户端继续使用协议版本 7；新能力会先检查服务器构建号，旧服务器不再因为无法识别
  新请求而停用聊天和快捷消息。更新固定服务器后即可使用完整的昨日房间记录。
- Codex 桌面版现在按真实安装进程识别；切回上号后，只要 Codex 仍然开着，工作图标就会保留。
- 新发送的链接预览会自动完整滚到输入框上方。固定服务器尚未升级时，房间记录会直接说明
  当前服务器暂不支持，不再一直显示“正在读取”。
