# 上号 ShangHao v2.9.1 更新公告

发布日期：2026 年 8 月 15 日

v2.9.1 是 v2.9.0 的 Windows 屏幕分享修复版。房间、语音、录音库和本地 AI 功能保持不变。

## 屏幕分享恢复

- 修复部分长时间运行的 Windows 会话中，已经选择显示器或窗口却提示桌面捕获无法启动的问题。
- 当正常采集和无系统声音重试都失败时，上号会按你选择的精确来源进入兼容采集，不会擅自分享其他窗口或整个桌面。
- 兼容采集以画面可用为优先；如果该路径无法带上系统声音，会明确显示本次只有画面，好友语音不受影响。
- 增加真实 Electron 2560×1440、24 fps 显示采集验证，并覆盖连续启动失败后的恢复路径。

## 抖音链接核对

- 上号会保留抖音直播间链接中的 `live.douyin.com/房间号` 和后续参数。
- 如果聊天中收到的是 `www.douyin.com` 首页地址，上号会按原地址打开，不会自行猜测或替换成某个直播间。

## 验证边界

- 自动化和本机真实采集验证不能替代所有显卡驱动、全屏游戏、多显示器与受保护窗口组合的点击测试。
- 精确来源兼容路径不保证携带 Windows 系统声音，但会优先保证选中的画面能够分享。
- 本次不修改信令协议和服务器版本门禁，不迁移或覆盖用户设置、聊天、录音、模型与转录数据。
