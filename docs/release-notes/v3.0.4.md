# 上号 ShangHao v3.0.4 更新公告

发布日期：2026-08-26

v3.0.4 重点完善本地录音工作流、快捷语音和模型对比体验。安装会保留现有设置、聊天、收藏、录音、模型目录与转录结果，不会把本地模型权重放进安装包。

## 多模型录音对比

- 在录音库中对同一条录音选择多个已安装模型，模型会按顺序逐个转录。
- 每个模型单独保留文字、分段、说话人、有效转录耗时和最终状态，完成后可以切换结果进行对比。
- 支持暂停、继续、停止、失败模型单独重试和已有结果保留；切换房间、设置或录音页面不会清空测试队列。
- 任务状态与检查点保存在本地，应用意外退出后重新进入可以继续未完成的模型测试。

## 快捷语音库

- 新增内置 AAC 快捷语音包，按原始文件名展示，支持全部、游戏、主播和未分类筛选。
- 支持搜索、添加状态反馈、五个全局快捷键、统一音量、开关音效和语音包导出。
- 快捷语音包统一按约 -16 LUFS 处理，减少不同语音之间忽大忽小的问题；录音库自动清理默认上限调整为 20 GB。

## AI、账号与界面

- 上号 AI 使用独立的紧凑问答入口，示例内容改为可通过互联网检索的游戏攻略问题，不再展示尚未完成的本地语音聊天上传提示。
- 压缩注册页、快捷消息页、模型管理页和诊断页的留白，修复小窗口内容截断、按钮尺寸跳动和快捷语音分类操作过多的问题。
- 统一房间控制、录音、屏幕分享、模型状态和快捷消息的图标与动效反馈，减少重复入口和无效装饰。

## 发布与兼容

- Windows 10/11 x64 NSIS 安装包：`ShangHao-3.0.4-Setup-x64.exe`。
- 房间协议版本保持 7，现有房间连接继续兼容；设置迁移版本更新至 33。
- AI 模型和用户录音仍保存在本机，不随安装包上传或覆盖。
