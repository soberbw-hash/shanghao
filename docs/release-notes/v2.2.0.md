# 上号 2.2.0

这一版把发布重点放回最基础的事情：五个人都能稳定说话、听见彼此，并且单个成员
的连接异常不会拖垮整个房间。

## 五个人真实媒体链路

- 发布前会启动五个相互隔离的 Electron 客户端，建立 10 条全互联 WebRTC 连接。
- 验收会核对 20 条定向入站 RTP 流，而不是只检查信令消息或连接状态。
- 第五位成员会以晚加入方式进入；随后销毁并重建一组连接，确认双方都能恢复收音。
- 保留五端语音兜底路由测试，验证每个人都能把实时音频定向发送给另外四个人。

## 降噪状态更可信

- DeepFilterNet 的 WASM 与模型资源会在应用启动后的空闲时段后台预热。
- 发布前会在真实 Electron 渲染进程创建 48 kHz AudioContext 和 AudioWorklet 节点。
- 只有处理节点实际创建成功后，界面才显示降噪已工作。
- 模型不可用时麦克风保持原声发送，不中断语音，也不连续弹出警告遮挡房间。
- 麦克风采集和降噪处理固定为 48 kHz；录音导出目标 32 kHz，与通话链路分离。

## 单成员自愈和诊断

- 诊断包记录每位好友当前使用 WebRTC 还是语音兜底、是否收到有效轨道，以及兜底
  队列长度、排队时长和丢帧数。
- 某位好友的入站 RTP 停止后，只恢复这一对媒体连接；其他人的声音不被重置。
- 屏幕分享的截图兼容路径只在接收端明确请求时启用，不再与语音就绪状态耦合。

## 安装

上号 2.2.0 支持 Windows 10/11 x64。下载
`ShangHao-2.2.0-Setup-x64.exe` 后可覆盖安装。

自动化覆盖不了运营商、路由器、声卡驱动与代理软件的全部组合。正式分发给好友前，
仍建议使用两台独立 Windows 电脑完成真实公网加入、五人语音、断线重连和屏幕分享
验收。
