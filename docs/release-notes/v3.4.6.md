# 上号 3.4.6

启动更轻，调音量更顺手。

## 本次更新

- **减少首页卡顿与叠音。** 资源在空闲时分批准备，启动期间不积攒提示音，避免解锁声音后一齐播放。
- **播放中也能调音量。** 语音包和音乐正在播放时，设置里的音量立即生效；新用户默认 30%，已有音量保持不变，界面按钮音量仍独立。
- **游戏悬浮窗更安静。** 游戏中保持鼠标穿透，减少鼠标轮询和重复置顶；悬浮窗不再单独占用任务栏预览，迟到加载不会重新弹出主窗口。
- **麦克风切换更稳。** 同设备调整降噪或人声增强时复用有效采集，减少反复打开设备；设置失败保留原状态，输入不可用时显示具体原因。

## 其他修复

- 修复组合快捷键先松开 Ctrl／Alt 后遗漏释放、失焦后仍保持按住说话的问题；注册失败保留旧绑定。
- Windows 窗口从官方多尺寸 ICO 读取图标；聊天滚动条颜色更淡。
- 诊断包保留最近事件，方便定位刚发生的问题，继续隐藏聊天、音频正文与凭据。

录音、聊天、模型和设置保留。更新下载完成后仍需手动点击安装。游戏帧率、RØDE 多应用并发和旧版点击升级仍需实机确认；本次不宣称解决所有系统驱动或第三方应用的占用问题。
