# 上号 ShangHao v3.2.0 更新公告

这次不是把房间重新装修一遍，而是给它加一套更可靠的底座：看得见运行状态，断线知道断在哪一步，升级后原来的东西还在。

## 更稳的日常使用

- 设置文件只在内容真正变化或需要迁移时写入。新加的往返与旧版数据夹具测试会检查设置、录音、模型和 Voice Memory 等已有资料的兼容性；不会为升级清理用户数据。
- 开发者诊断加入 Main / Renderer 的内存、进程与 DOM 趋势。指标是有界统计，不收集聊天正文、转录正文或音频内容。
- 聊天链接不再请求第三方 favicon 服务；没有本地图标时用通用链接图标。

## 游戏状态与手机麦克风

- Windows 游戏探测优先由 Rust Core 提供进程和前台窗口事实，TypeScript 继续负责游戏规则；原生探测不可用才用 PowerShell 回退，减少常态扫描开销。
- 手机麦克风配对会区分申请配对、等待手机、协商、已连接、恢复和失效；断开后可重新获取配对码。
- 手机麦克风服务从 root 改为独立受限账号运行，增加不包含个人内容的健康状态与回滚部署路径。

## 质量门槛与验证边界

发布流水线新增迁移、N-1 数据兼容、手机麦克风和运行状态测试；Linux CI 的 Windows 专用测试与图形显示条件也已修正。原有五人语音、媒体恢复、音频处理、录音、屏幕分享和 AI 算法不因本次整理而重写。

自动化通过不等于真实好友的听感、不同手机浏览器、公网 TURN、游戏 FPS 或旧安装版客户端完整“发现—下载—安装”流程已通过。这些项目需要按真实设备分别验收；未验证时我们会明确标注。
