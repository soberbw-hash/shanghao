# 上号 2.2.2

这一版集中修复多人房间中最严重的单向无声问题，同时收顺角色退出动作，并堵住
昵称规则可被数字后缀绕过的问题。连接协议保持为 6，固定服务器无需更换配置。

## 五人语音

- 远端音频不再把“收到 RTP 数据”误判为“已经能听见”。客户端会继续确认浏览器
  已经解码出真实音频波形，再决定是否关闭该成员的信令音频兜底。
- WebRTC 接收轨道增加稳定的解码播放链路；共享混音器会自动恢复被系统挂起的音频
  上下文，降低晚加入成员只说得出、听不见的概率。
- 自动验收使用 5 个独立 Electron 客户端，验证全部 20 条成员到成员的音频方向，
  同时覆盖第五人晚加入和断线后的双向恢复。

## 细节修复

- 退出频道时角色立即开始沿路线离场，不再先卡住一小段；到达出口附近才自然淡出。
- 昵称限制同时在客户端和服务器执行，数字前后缀、符号分隔与常见替写不能绕过。

## 安装与测试

上号 2.2.2 支持 Windows 10/11 x64。所有参与者都应升级到
`ShangHao-2.2.2-Setup-x64.exe` 后再进行多人测试。建议依次验证两人、四人和五人，
并让最后加入的人分别听取每一位既有成员的声音。
