# 上号 v2.8.0

> 2.8.0 是 2.6.0 之后的下一次正式更新，合并了本地 2.6.1、2.7.0 与 2.8.0 三个开发阶段。更新安装包一次即可获得下面全部改进。

## 💬 聊天更可靠

1. **消息不会悄悄丢失**：文字、图片和链接收到服务器确认后才显示发送成功。
2. **断线自动重试**：网络短暂波动时使用同一条消息继续发送，不会重复写入聊天记录。
3. **失败可以重发**：确实没发出去时保留原内容和重新发送入口。
4. **图片与链接更顺手**：修复图片复制失败和最新预览被输入框遮住；图片可前后翻看，内容可快速复制或收藏。
5. **更新保留记录**：聊天、收藏和最近 14 天房间记录继续保存在本机，覆盖安装不会清空。

## 📼 录音库与昨日房间

1. **播放完整**：修复部分 M4A 一直读取、不能拖动或无法完整播放的问题。
2. **前后切换与倍速**：支持上一条、下一条，倍速按钮按 1 倍、1.5 倍、2 倍循环。
3. **整理更清楚**：录音按日期、房间和当天编号命名，可收藏筛选，也能一键清理不足 10 秒的片段。
4. **默认 10 GB**：超过空间上限后从最旧的未收藏录音开始整理。
5. **记录具体的人和游戏**：昨日房间会显示谁来过、玩了什么和大约玩了多久，并正确处理跨午夜记录。

## 🎙️ 语音、角色与屏幕分享

1. **五人互听继续保护**：保留后加入成员互听、ICE 恢复、TURN、弱网兜底和每位好友的本地音量。
2. **人声链不回退**：回声消除、DeepFilter 降噪、自动增益、人声增强、低切与说话状态同步全部保留。
3. **角色不再跑错座位**：修复说话后跑到三号位、切房卡在奔跑途中和状态动画残留。
4. **Windows 分享修复**：只在你明确勾选时捕获系统声音；来源临时启动失败会自动重试同一个窗口或显示器。
5. **离开与弹窗更顺**：分享、悬浮窗和房间连接并行收尾；昨日房间与设置切换不再让整张窗口实时做高耗模糊。

## 🧠 本地模型下载

1. **大小提前可见**：VibeVoice 约 **1.6 GB**，Qwen3.5-4B 约 **8.7 GB**。
2. **进度真实可见**：下载时显示已完成大小、总大小和实时百分比。
3. **下载源自动切换**：优先尝试国内可用镜像，失败后自动尝试 Hugging Face。
4. **可以暂停和续传**：关闭上号、断网或重启后不会故意从零开始。
5. **游戏优先**：检测到游戏时降低下载和后台任务优先级，不抢语音、游戏和屏幕分享资源。

## 🪟 Windows 与安装更新

1. **运行环境升级**：更新 Electron、React、Vite、Tailwind、TypeScript 和 Windows 打包工具。
2. **界面与动画保持原样**：五工位、动物角色、聊天、录音库、悬浮窗和全部现有动画都保留。
3. **覆盖安装更安全**：新版文件清单只清理明确属于上号的程序文件，不会递归删除整个自定义目录。
4. **旧版可以直接升级**：没有文件清单的旧安装也能原位覆盖，不要求先卸载。
5. **本地数据独立**：昵称、设备、音量、聊天、收藏、录音、昨日房间和已下载模型都不属于程序清理范围。

## 🧰 代码整理

房间通信继续保留统一入口，聊天、连接、屏幕分享和本地保存改由职责明确的内部模块负责。五人 WebRTC、服务器架构、用户操作和 UI 没有重写；这次整理是为了以后修一个功能时更不容易影响其它功能。
