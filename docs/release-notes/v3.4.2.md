# 上号 3.4.2

房间有了记忆，录音整理与分享更清楚，修复了一批日常操作问题。

## 这次更新了什么

- **房间记忆。** 在「设置 → 账号 → 我的房间 → 管理」记录成员称呼、关系和偏好。AI 问答、录音整理和每日总结参考本房间记忆；房主可以编辑或删除自动提取的条目，并查看出处。
- **录音三步处理。** 开始转录 → 整理内容 → 上传到服务器。整理完成后才能分享摘要到录音原房间，供每日总结参考；原始录音与本地标记不上传。
- **静音状态保持。** 挂机回来按离开前的状态恢复麦克风；修复快速反复按住静音后卡住的问题。
- **快捷消息更直接。** 语音和音乐共用一个快捷键总开关，默认关闭。按钮按一行能放下的数量完整展示，不再翻页；设置槽位可右键清空、拖入重新绑定。
- **头像能保存了。** 32 个重绘的内置头像，先预览，再明确保存；修复内置头像格式与反复试选限流问题。

## 录音与 AI

- 自动整理、整理后自动上传默认关闭，在 AI 功能中按需开启。
- 整理与问答合并模型选择，默认房间云端，也可选择自定义 API；常用设置移到模型前面。
- 铅笔入口可修改录音名称，卡片分别显示“录制时间 12:36”和带单位的总时长。
- “清理废弃录音”扫描不足十分钟或整段静音的录音，先预览、试听和选择，再移入回收站。收藏、带标记和读取失败的录音受保护。
- 本地游戏启动与退出自动标记默认开启，回放时可查看发生时间与备注。
- 游戏助手统一先给结论与重点，不再给普通问题附加无记忆提示；分享到聊天显示机器人头像与“游戏助手”，最近提问可删除。

## 房间与设置

- 减少切换、退出房间时的读取提示闪现、白屏和弹窗尺寸跳变。
- 房间顶部信息居中，查找输入提示为“频道号”，按钮保持横排；修复左侧叶子摆动的硬边。
- 重新加入房间会重新随机角色，好友上线提醒默认开启。
- 快捷键冲突只关闭失败槽位并保留配置，不再关掉整个总开关；关闭按键时不显示无效提示。
- 上号后台自动检查并尝试恢复自身网络规则；必要的 Windows 授权仍由用户确认，取消后不反复弹出。
- 更新公告首屏展示重点，完整变化按主题展开；可直接关闭，在「设置 → 关于上号」再次查看。

各房间的记忆和上传摘要分别保存，权限由服务端核验。自动记忆只从已经上传的整理摘要提取，不扫描未上传的本地录音。人工修改和删除会保留，提取失败不会编造记忆。

更新可以后台下载，安装并重启仍需主动点击。真实五台设备听感、旧版完整升级、游戏内全局快捷键、USB 热切换和系统授权流程继续单独实测，自动化不替代这些结果。
