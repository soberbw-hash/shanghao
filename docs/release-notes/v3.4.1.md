# 上号 ShangHao v3.4.1 更新公告

这一版集中处理日常开黑时的界面、动效和退出收尾，并加入名场面导出与托盘提醒。正式支持 Windows 10/11 x64。

## 房间与聊天

1. **回来就进上次房间。** 登录状态可安全恢复，入口突出上次房间，创建和查找缩为次要操作。登录页与房间页使用同一账号头像；房间管理集中在账号设置，图标可选择颜色，固定频道号不再显示为输入框。
2. **邀请能找到正确房间。** 复制内容包含房间名称、六位频道号和网页入口。朋友点击后可打开上号，首次登录后继续加入该永久 RoomID；没有安装时可先下载。
3. **快捷消息完整显示。** 语音和音乐依据字符占用、实际文字宽度及窗口宽度分页，放不下的整项收起，不再露出半个按钮。所有自定义绑定保留。退出或切换房间立即停止音乐，迟到加载不能重新播放。
4. **通知统一堆叠。** 折叠后保留背后卡片的层次；重复敲门提示合并，聊天里的敲门记录颜色一致。补齐加入、离开、暂离、返回等音效，音乐标记与人物状态留出间距。

## 画面与悬浮窗

1. 启动等待页面平滑退出，房间入口加载占位保持尺寸；设置先预加载再切换，首次场景资源提前准备。换座连续融合步行动作，减少上下跳动；视觉工作在隐藏后暂停，通话和录音继续运行。
2. 门缩小约 15%，只保留中间小区域可点击，并下移到前景叶子后；日历稍向右上调整，窗帘和叶子摆动更明显。人数使用对齐的胶囊，切房按钮更紧凑；暂离成员名字和“暂离”不随角色缩成小字。
3. 悬浮窗使用独立页面，修复误加载主界面、黑底、滚动条与高度异常。无边框游戏切换时恢复无焦点置顶，不抢游戏输入。
4. 游戏目录扩展到 60 项，补充 LoL 大厅、GTA V 增强版及常见合作、射击和单机游戏；通用进程增加标题/路径限制。电脑屏幕采用统一的游戏类型插画与真实游戏名称。
5. 主应用的窗口、启动、关于、托盘、官网及安装器采用用户提供的同一高清耳机原稿；每版安装包保存原 PNG 和校验清单。

## AI、录音与后台

1. 上号 AI 改用用户选择的透明耳机机器人，移除示例提问。答案旁可明确点击发送到聊天；长答案分段发送、失败可续发。余额、权限、网络和服务错误分别说明。
2. 录音标记可试听并导出固定 **M4A（AAC）** 名场面。短、标准、长及自定义时长会保存；首尾淡入淡出，文件仅写本机、重名不覆盖、原录音不变。首次说明、文件夹入口和文件拖出入口一并提供。
3. 托盘模式下关窗可选择退出房间后隐藏、继续通话或取消。通话/录音状态写在托盘提示里；好友上线提醒默认关闭，开启后后台有界检查，点击通知只打开房间预览，仍需明确加入。
4. 诊断展示直接结论和小尺寸按钮，完整技术资料可单独导出。连接恢复沿用成员/链路 Owner，本机麦克风输入结束时只尝试恢复当前输入；设备和权限问题不会触发全房重置。
5. 后台任务共用资源调度、带取消与超时；主程序普通权限启动。系统规则修复需明确点击后按需提权，启动读取失败不会直接弹 UAC。

## 验证与边界

- 本地检查覆盖类型、Lint、906 项 smoke、迁移与旧版存储、手机麦克风侧链、AudioWorklet、原生屏幕捕获、五人 20 条音频链路及媒体恢复。角色连续换座、途中改目标、失败收尾，以及快捷消息、独立悬浮窗与麦克风恢复在隔离 Electron 中检查。
- 游戏识别验证的是进程/标题/路径规则；不同地区服和反作弊环境仍需实机核对。模式、英雄、队伍人数需要游戏提供真实接口，本版不以进程名猜测；独占全屏不能保证显示外部悬浮窗。
- 自动化不代表真实 120/144 Hz 帧率、朋友端听感、USB 实机恢复、第三方聊天软件拖放或系统通知到达已验收。
- 旧客户端的“发现 3.4.1 → 下载完成 → 用户点击安装并重启”仍需实机操作。没有自动安装，也没有覆盖真实账号、聊天、录音、Marker、模型或设置进行升级实验。
