# 上号 2.1.1

这一版补齐固定好友频道的角色唯一占用和单成员本地音量控制，并继续修复快速切换
座位时的角色动画状态。

## 角色不会重复

- 进入频道前会显示已经被好友选择的角色，并禁止再次选择。
- 信令服务器会对加入和房间内换角做原子校验；即使两个人同时抢同一个角色，
  也只允许一个人成功。
- 正常离开后角色立即释放；异常掉线会保留短期重连机会，超时后自动释放。

## 每位好友单独调音量

- 点击场景中的好友角色，可打开紧凑的本地声音面板。
- 支持 `0–200%` 音量、一键“仅我静音”和恢复 `100%`。
- 调整只影响自己的电脑，不会修改对方麦克风，也不会影响其他成员。
- 音量会按好友昵称保存在本机，WebRTC 与语音兜底切换后继续生效。

## 其他修复

- 昵称规则统一到客户端和服务器共享模块，减少通过变体绕过校验的情况。
- 角色移动状态支持快速操作打断，减少换座时的漂移和动画残留。
- 增加角色并发抢占、离开释放、音量边界和界面行为回归测试。

## 安装

上号 2.1.1 支持 Windows 10/11 x64。下载
`ShangHao-2.1.1-Setup-x64.exe` 后可覆盖安装。

本版本客户端需要与同一版本的上号信令服务配合，才能启用服务器级角色唯一占用。
