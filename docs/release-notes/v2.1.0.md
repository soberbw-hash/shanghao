# 上号 2.1.0

这一版集中修复五人语音可靠性，并把自动离开、屏幕分享、角色模块和动效系统
收敛为可以继续维护的产品架构。

## 最重要的修复

- 第四、第五位好友加入时，Offer、Answer、ICE 和恢复操作会按成员串行处理，
  避免并发协商互相覆盖。
- WebRTC 显示“已连接”后不会立即关闭语音兜底；必须确认真的收到对方 RTP
  音频包才切换。若音频包停滞，会只为受影响的成员恢复 Relay 兜底。
- 远端成员继续共用一个音频混音器，WebRTC 与 Relay 之间按成员切换，
  避免重复播放或某一位成员彻底无声。
- 信令重连增加短期会话令牌，断线恢复时能更安全地识别原会话。

## 使用体验

- 自动“离开一下”只看 Windows 鼠标键盘空闲时间，不再被说话、游戏、
  屏幕分享或录音错误阻止。
- 自动返回与手动返回使用同一开麦规则：扬声器开启则开麦，扬声器关闭则闭麦。
- 游戏自动识别可以在设置中立即关闭或开启，不要求重启。
- 提示音只保留总开关和总音量；自己进入、自己退出、好友加入、好友离开使用
  不同声音。
- 角色渲染、移动、标签、反应和性格配置已拆分，现有场景与动画保持不变，
  后续调整不会继续堆进一个超大组件。
- 屏幕分享的采集、Track 生命周期、内容保护和独立观看窗口统一由一个 Manager
  管理；观看窗口只拥有必需的最小权限。

## 安装与平台

上号 2.1.0 仅正式支持 Windows 10/11 x64。下载
`ShangHao-2.1.0-Setup-x64.exe` 覆盖安装即可。仓库不再提供 macOS 打包脚本或
macOS 安装包。

本版本的自动化会验证五个模拟客户端之间的定向音频路由，但真实公网双机、
三至五人一小时语音、720p/1080p 分享和代理/TUN 切网仍需在发布前人工验收。
