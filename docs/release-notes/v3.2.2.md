# 上号 ShangHao v3.2.2 更新公告

这一版继续收紧长时间语音的听感与设置操作，同时重新整理房间天气和仓库主页。Windows 10/11 x64 是正式支持平台。

## 语音与快捷消息

- 麦克风语音保护对近端说话、远端声音与双讲的处理更平滑，减少人声被降噪误压；本地人声增强继续在音频 Worklet 中处理。远端各路的响度学习只参考有效说话片段，并限制增益变化与峰值。
- “我的快捷消息”扩充为八个语音／音效槽位和五个音乐槽位。槽位可以拖拽绑定，音频库顶部同时管理播放开关与音量；主界面的快捷项随文字宽度排布。
- 麦克风体检与设备路由增加针对性检查，保持手机麦克风和桌面麦克风进入同一房间处理路径。

## 房间与界面

- 窗外加入不同速度的云层、夜间光雾和窗边植物摆动，窗帘与叶片的轻动画更可见。城市和窗框保持稳定；页面隐藏或减少动态效果时暂停纯视觉运动。
- “问 AI”入口和弹窗减少重复图标与口语化说明；更新提示按钮在窄窗口中自动换行，避免右侧文字被裁切。
- 模型操作菜单离开后收起；设置中心“我的快捷消息”顶部空白收紧。

## 说明与验收

- 仓库主页按使用场景逐项介绍房间、五人语音、聊天、手机麦克风、录音与 AI；补充 DeepFilterNet3、近端/远端说话检测、双讲保护和 USB/Web 配对的真实实现。
- 自动化验证不能代替真实五人听感。旧版客户端实际完成“发现 3.2.2 → 下载 → 用户点击安装并重启”，以及朋友在另一台设备上听到手机麦克风，仍需分别实测。安装动作不会由后台自动执行。
