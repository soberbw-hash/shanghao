# 上号 v3.4.20 更新说明

本次更新集中改进房间体验、语音回溯和设置界面。

- 房间管理中可直接修改名称和头像，保存对话与回溯设置使用同一入口。
- 设置页面统一浅色背景，优化界面文字、头像选择及录音库布局。
- 适配和平精英模拟器游戏窗口，游戏名称显示为“和平精英”。
- 临时联机增加服务器房间和直接连接的选择，两者无需注册账号；跨网络直接连接可能需要发现或中继服务。
- 完善录音转录、游戏语境和房间纪事相关流程，云端功能取决于服务器部署及配置。
- 临时联机可选择新版头像，简化首页入口；改进房间角色动画异常时的恢复。

角色恢复仍需在实际房间验证；真实多人通话、长录音和旧版升级须单独实测。云端服务的可用性取决于实际部署状态。
