# 上号 v2.6.1

> 本文件是正式发布前准备稿。v2.6.1 当前尚未推送、打包或发布。

## 聊天可靠发送

文字、图片和链接预览现在都会等待服务器确认。短暂断线或确认丢失时，上号会用同一个
消息 ID 安全重试；服务器不会重复广播。确实没有发出去的消息会保留并显示“重新发送”，
不再出现自己看见消息、朋友却完全收不到的静默失败。

## 录音库播放

录音协议补齐 M4A 的流式读取和 Range 响应。软件内播放器可以按需读取、拖动进度、定位
录音标记并切换倍速。媒体读取失败时不会跳走或清空选择，原文件仍保存在本地目录。

## 版本一致性

客户端和 signaling server 都能检查最低版本。正式发布并最后提升生产门禁后，旧版、
缺失版本和格式错误的客户端都不能进入一号房或二号房；本轮开发阶段没有修改生产门禁。

## 昨日房间与视觉

跨午夜在线时长按上海自然日正确拆分，成员按稳定资料身份去重，服务重启后游戏参与统计
继续累计。角色动画不再把像素值当成场景坐标；五个坐姿按柯基体量校准，鸭子重新居中，
昵称框给普通昵称留出更多空间。

## 更新历史与 Codex 图标

更新弹窗改为分类详细内容和自动分页，可显示本地图片与使用方法。设置页离线保留从 0.1.1
到当前候选版本的 64 条可核验历史。Codex 工作状态优先读取官方 AppxManifest 图标，并保留
Windows 可执行文件图标作为回退。
