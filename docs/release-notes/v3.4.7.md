# 上号 3.4.7

录音库标记更可靠，进房过程也更轻一些。

## 本次更新

- **修复重复的精彩时刻区域。** 录音库的录音片段和转录/模型对比区域使用各自稳定且唯一的组件标识，不会因 React 复用组件状态而把同一组精彩时刻重复渲染。
- **回放时不再误加标记。** 标记仅在实际录音期间接受；回看录音或在对比页面点击播放进度条，不会把播放位置写成新标记。重复标记 ID 也会被忽略。
- **减轻进入房间时的瞬时卡顿和叠音。** 房间设备初始化前暂停可选的视觉资源预热，进入并完成页面切换后再恢复。自动录音仍会启动，但不再与进房提示音叠播。
- **麦克风无响应时给出有限等待和明确提示。** 采集请求超过设定等待时间会返回可识别错误；若底层请求迟到返回，会释放迟到音轨，避免留下未使用的采集流。

## 验证与边界

- TypeScript 类型检查、定向 lint 和桌面 smoke 已通过；隔离 Electron 回归连续跳转 120 次、切换对比 8 次，始终只显示一个精彩时刻区域和一个标记，且没有写入用户录音标记。
- 自动化证据不等同于真实房间的帧时间、声音表现或麦克风驱动兼容性；需要用户在开发版/正式版上继续实际使用观察。
- 录音、聊天、设置、模型和历史记录均保留。本次没有清理或重置用户数据。
