# 上号 2.4.0

本轮不改变固定服务器架构，也不重写已经验证通过的五人语音播放链路。重点是让弱网恢复、
Windows 权限、开机启动、防火墙和 TURN 部署更可控，并补齐日常使用中的音量与录音体验。

## 五人语音与带宽

- 五个独立 Electron 客户端继续验证全部 20 条定向 WebRTC 音频路径、第五人晚加入和
  单成员链路重建后的双向恢复。
- 信令语音兜底由固定 12 秒预热改为按成员启用；只有该成员尚未产生可播放 PCM，或明确
  请求恢复时才发送，不影响其他已正常连接的好友。
- 自适应活动门控保留语音起始与尾音，同时抑制静默和单次键盘瞬态；一个成员异常时优先
  ICE restart，失败后才局部重建连接。

## Windows 可靠性

- 正式 EXE 使用 `requireAdministrator`，开发模式不提权。
- 开机启动使用当前用户、交互式、最高可用权限的计划任务，延迟 5 秒，并会在更新路径后
  自动修复。
- 防火墙只管理 `ShangHao Network` 组内属于当前 EXE 的 TCP/UDP 入站与出站规则；设置页
  可以查看和修复，不会删除其他软件或用户规则。

## TURN 与体验

- 服务器提供受 Token 保护的 `/ice-config`，以短期 HMAC 凭据支持 TURN UDP/TCP 和可选
  TURNS，不向客户端或日志暴露共享密钥。
- 新增麦克风发送音量、扬声器总音量、自动入房录音、珍藏未读与更完整的悬浮窗状态。
- 聊天图片会在发送前压缩为高质量 WebP，消息中显示轻量缩略图，点击即可查看清晰大图；
  同时校验文件大小、格式与真实图片签名，避免伪造图片占用房间带宽。
- 屏幕分享停止、窗口退出和外链打开使用统一安全清理，减少残留轨道、黑窗和重复关闭。

## 使用建议

建议更新后完成一次麦克风、扬声器和降噪检查。多人开黑前，可用两台真实 Windows 电脑
快速验证入房、断线重连、设备切换和屏幕分享。
