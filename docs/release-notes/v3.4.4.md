# v3.4.4 更新公告

## 这次改了什么

- **回顾更有意思。** 聚焦真实笑点、精彩互动和下次约定，游戏在回顾中简短概括，不再逐人列出时长。
- **弹窗更清楚。** 更新公告和其他窗口统一模糊背景，调整字号、行距及窄窗口滚动，避免底层文字重叠。
- **素材入口更整齐。** 关于页图标、说明和按钮重新对齐，补强主软件与上号素材的窗口图标设置。
- **云端回答有备用。** 原模型暂时不可用时尝试智谱备用接口，取消后不继续请求，遇到限速会暂停重试。

![新的每日回顾排版，使用演示数据](https://raw.githubusercontent.com/soberbw-hash/shanghao/v3.4.4/docs/readme/v344/daily-report.png)

## 每日回顾

笑点、互动和约定参考本房间明确上传的整理摘要，不编造战绩、台词或关系。重复片段合并展示，已有历史回顾保留；新生成内容采用简短自然的风格。原始录音及未上传摘要仍留在本机。

## 界面与图标

更新公告、确认窗口及音频菜单统一遮罩和背景模糊。长回顾可以滚动；关于页的上号素材入口使用整齐的图标、说明与操作布局。主窗口和素材窗口明确设置各自图标，正式安装包保留官方耳机原图。麦克风启动失败时更明确地说明权限与设备检查，不自动更改 Windows 或 RØDE 设置。

## 云端备用

服务器保持原模型优先，故障时尝试 GLM-4-Flash-250414。备用有取消、限速冷却、并发保护和总超时；房间记忆仍按原房间读取，密钥不进入客户端或公开仓库。备用接口目前不带联网搜索，涉及最新版本、价格等会说明无法联网核实。

自定义 API 可填写兼容地址和模型，用于录音整理与问答，不替换音频转录模型。更新下载完成后，仍由用户点击安装并重启。
