# 上号 ShangHao v3.0.5 更新公告

> 本版本基于 v3.0.4 完成架构、稳定性、性能与模型测试收口，面向 Windows 10/11 x64 发布。

## 这轮实际收口

- 桌面包 `lint` 现在执行真正的 ESLint，而不是把 TypeScript 检查冒充 lint；根目录 ESLint 与格式检查保持通过。
- 对 IPC、AI 模型管理、AI Runtime、RoomClient、RoomPage 和信令服务增加只降不升的规模护栏。当前没有为了通过检查而放宽既有 RoomClient/RoomPage 上限。
- 设置页的诊断快照和 Windows 集成状态只在进入“诊断”页时读取；诊断页外不启动对应的诊断轮询。
- 自动录音清理改为移入 Windows 回收站后再从录音库索引移除，避免后台维护永久删除用户文件。收藏和带标记录音仍然不会被自动清理。
- 对 VibeASR/VibeVoice 做了实际引用核查。它仍被运行时清单、运行时管理、语音记忆错误状态和测试使用，因此保留，不把当前能力误判成死代码。
- 修复多模型对比恢复时将其他模型的旧转录误当作当前模型断点的问题；Cohere 的可选 ForcedAligner 不再阻塞基础转录，缺失或不兼容的 checkpoint 会自动重新尝试一次。
- 模型对比页新增一次性 JSON 导出，整理每个模型的耗时、RTF、文字、分段时间轴、说话人、字级时间和失败信息；CER 留给外部 GPT 分析，本地不做判断。

## 兼容性与未宣称边界

- 不改变 WebRTC、五人房间、屏幕分享、录音格式、AI 模型文件和既有模型对比数据结构。
- 手动删除录音仍是明确的永久删除操作；只有自动维护/配额清理使用回收站路径。
- 自动化检查不能替代真实 Windows 长时运行、多人语音听感、模型连续挂机、显存/内存曲线和异常退出恢复验收；这些需要在目标电脑上审核。

## 验证记录

- 根目录 ESLint 与 Prettier 检查通过。
- 全工作区 typecheck、桌面 smoke 回归、模型对比导出回归、生产构建和 `git diff --check` 通过。
- GitHub Release 工作流会在 Windows runner 上继续执行 native、完整 smoke、音频/媒体、Windows 安装包运行时、SHA256 和发布资产校验。
