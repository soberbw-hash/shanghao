# 上号 ShangHao v3.4.0 更新公告

这一版上线动态私人房间。朋友可以拥有自己的频道，创建、查找、收藏与管理都在软件内完成。正式支持 Windows 10/11 x64。

## 私人房间

1. **创建自己的房间。** 每个登录账号最多创建三个房间，可设置名称并选择 20 个内置图标；随机生成六位频道号，也可以填写未被占用的号码。支持前导零。
2. **通过频道号找朋友。** 查找后先看房间信息，再明确点击加入。没有公开房间列表；创建、查找和收藏都不会自动把你拉进房间。
3. **最近、收藏、我的房间。** 成功加入后记录最近房间；收藏由自己决定，导航记录按账号和服务器保存。
4. **五人容量，房主也遵守。** 每间最多五人，包含房主。房主离线后房间继续存在；房主可修改名称与图标、移出成员、封禁、解封和删除房间。
5. **频道号与数据身份分离。** 房间有永久 RoomID；删除后的频道号冷却 30 天，重新使用也不会继承旧聊天、收藏或权限。
6. **切换时正确收尾。** 离开旧房间前处理录音、共享和连接资源。录音保留当时的房间名称与身份；旧一号房、二号房的本地资料仍可读取，新首页改用私人房间入口。
7. **正式服务同步升级。** 官方连接使用 HTTPS/WSS；只迁移原来的官方地址，保留自建服务器配置。旧客户端收到明确的升级提示，需更新到 3.4.0 后使用私人房间。

## 稳定性与维护

1. 语音记忆的转录准备、分段重试和整理任务独立管理，入口负责协调；异常模型输出不再当作成功正文。
2. ASR 的 FFmpeg 预处理与推理共用计算租约，模型和 Runtime 下载共用压力等待与限速；取消等待不能释放其他任务正在使用的资源。
3. 房间目录、最近记录和录音归属增加校验、串行事务与原子保存；文件损坏时保留原数据，拒绝空数据覆盖。
4. 通用设置可按需查看模型、Runtime、录音、更新缓存和临时文件占用。清理只处理能确认归属的过期 ASR 临时文件，不删除模型、录音或待安装更新。
5. 收紧 Benchmark 嵌套参数与房间 IPC 边界；架构预算采用只降不升的检查，避免核心模块靠抬高上限继续膨胀。
