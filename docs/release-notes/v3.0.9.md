# 上号 ShangHao v3.0.9 更新公告

这版先把“临时接电话”这个真实场景做好：按一个快捷键，电脑声音和麦克风一起安静下来；同时修掉房间角色偶发卡住的问题，让日常使用更稳。

## 📞 电话模式：接电话时一键静音电脑

- 可选择“按住快捷键”：按住期间静音，松开后恢复；也可选择“按一次切换”：按一下静音，再按一下恢复。
- 支持空格、方向键、普通组合键、Win 组合键和鼠标侧键。
- 电话模式会处理 Windows 当前所有活动的输入和输出设备，而不只是上号自己的麦克风和扬声器。
- 启用前逐个确认设备已经静音；发生错误、助手退出或状态无法确认时，上号保持静音保护并提示具体原因。
- 上号正常退出时恢复静音前状态；异常断开、锁屏和休眠不会偷偷解除静音。

> 注意：独占音频、ASIO 或硬件绕过 Windows 共享端点控制的程序可能不受软件静音影响。重要通话请同时使用麦克风或耳机上的硬件静音。

## 🐾 房间动作更稳、更顺

- 修复切换座位、点击离开时偶发卡在原地反复抽搐的问题。
- 角色快速改目标时正确收束上一段动作，动画异常也会回到稳定状态，不会一直停留在“走路中”。
- 修正缩放场景下的坐标计算，减少走跑动作的跳动感，保留原有动画和房间视觉。

## ⌨️ 快捷键设置更直白

- 空格不再因为“按键说话”默认配置而被错误占用；只有启用该功能时才会提示冲突。
- 快捷键冲突提示会直接告诉你被哪个上号功能使用。
- 支持方向键、编辑键、小键盘和常见组合键；危险的系统关闭、锁屏组合仍会被拒绝。

## 🔒 其他稳定性

- 新增电话模式主进程与原生助手回归测试，覆盖 20 轮真实 Windows 设备静音/恢复、错误响应、进程断开和重启保护。
- 不改变 ASR 模型、ForcedAligner、原始精细时间轴、阅读自然段或 Benchmark 统计逻辑。
