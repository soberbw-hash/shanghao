# 上号 3.4.8

修复本地语音模型准备和电话模式快捷键启动时机，让下载完成后的模型更容易正常启动，也减少进入通话模式时按键没有生效的情况。

## 本次更新

- **修复本地模型无法准备。** 本地 ASR 模型已下载但应用准备失败时，受管私有 Python Runtime 会按应用需要完成初始化，不依赖用户另行安装系统 Python。初始化失败会返回明确状态，并支持从模型卡片重试。
- **修复启动时的通话快捷键竞态。** 电话模式在启动全局输入钩子前先注册按键监听，避免钩子启动瞬间按下快捷键、监听尚未就绪而漏掉事件。
- **保留游戏状态下的按键处理。** 回归覆盖游戏活动抑制逻辑和全局按键路径，确保该路径不会因普通游戏活动检测被整体屏蔽。

## 验证与边界

- 模型 Runtime、模型初始化失败提示和重试路径，以及电话模式快捷键的定向自动化回归已覆盖；合并到发布标签后的完整检查由 GitHub Actions 执行。
- 自动化测试不能代替每款游戏的真实输入环境验收。独占全屏、无边框窗口、反作弊软件和键盘驱动组合仍需在实际游戏中确认。
- 本次不删除本机录音、模型、配置或缓存；已下载模型和现有用户设置继续保留。
