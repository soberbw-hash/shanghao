# ShangHao 3.0.1（本地开发轮）

> 本文档记录 3.0.1 的本地开发内容，不代表已发布版本。

## 性能与渲染管线

- 屏幕分享兜底帧的过期判断下沉到独立子树，移除 RoomPage 的屏幕帧时钟。
- RoomPage 音频状态改用选择器；成员比较移除热路径 JSON 序列化并复用稳定对象。
- 屏幕帧重复序列不再触发 store 更新；Overlay reconcile 心跳调整为 2 秒。
- 分离屏幕分享窗口的 Relay 帧同步合并为 200ms 批次，降低高频 IPC。
- 角色组件增加稳定 props memo，语音光环继续走 CSS 变量和 VisualRuntime。
- 音乐/工作活动比较改为原始字段键，避免渲染依赖中的 JSON 分配。
- RuntimeHealth 补充 GPU compositing、rasterization、WebGL/WebGL2、视频编解码和 ANGLE/backend 信息。

## 功能漏项

- 增加 Character Pack Protocol 的 renderer、状态、锚点、尺寸、重叠和 metadata 类型。
- “上号”快捷语音仅做 -5 dB 局部增益修正，其他音效保持不变。
- ResourceScheduler 接入自动更新下载：实时语音、屏幕分享或 Peer Recovery 时自动下载延后，手动下载仍由用户明确触发。

## 验证边界

- 类型检查和房间/屏幕分享聚焦测试通过。
- 完整桌面 smoke 通过：340/340。
- 真实设备 FPS、1% Low、P95/P99、GPU/VRAM、五人语音、1080p 分享、长会话仍需人工采样。
- 本轮不推送、不打包、不创建 Release。
