# ShangHao 3.4.4 当前发布基线

## 当前边界

- 当前本地基线：ShangHao 3.4.4；本地工作区是唯一发布基线。
- 发布前核对 GitHub 与 CloudBase 正式版均为 3.4.3，按用户桌面流程递增至 3.4.4。GitHub、更新 metadata、官网与服务器已为 3.4.4；正式产物及上线结果见本轮发布记录。
- Windows 10 / 11 x64 是正式支持平台。自动化结果与真实硬件听感、显存、帧率和公网恢复测试分开记录。
- 不删除用户录音、模型、配置、缓存或既有能力；本地 AI 结果默认留在本机。
- 本轮优化弹窗背景模糊、每日回顾和关于页素材入口，补强主软件与素材图标，增加云端备用。上版游戏画面、记忆与分享能力全部保留。
- 实现与回归见 [剩余工作记录](remaining-work.md)，用户说明见 [v3.4.4 更新公告](release-notes/v3.4.4.md)。
- 本轮发布证据见 [3.4.4 发布核对](release-verification-v3.4.4.md)；上一正式基线见 [3.4.3 发布核对](release-verification-v3.4.3.md)，真实设备验收仍独立。

## 架构与实时优先级

- Electron 主进程负责窗口、显式 IPC、录音文件、AI Runtime、模型下载、诊断和 Windows 集成。
- Renderer 使用 React、Zustand、GSAP / Framer Motion；视觉页面隐藏后暂停纯视觉工作，实时连接、音频、录音和信令不随视觉生命周期暂停。
- 五人私人房间继续使用 WebRTC Mesh，并保留信令音频/屏幕兜底、ICE/TURN、AEC、DeepFilterNet、VAD、-16 LUFS 好友响度匹配和资源调度。
- 服务端持久化目录是房间身份与房主权限的事实来源；频道号仅用于查找，正式官方入口使用 HTTPS/WSS。
- 资源优先级：实时语音与房间交互高于后台 ASR、本地整理和模型下载。

## 账号、录音与 AI

- 当前主账号服务为 CloudBase：手机号验证注册，账号或手机号登录，Session 由 Windows 安全存储保护；Supabase 仅保留旧部署兼容路径。
- 原生房间录音使用软件已知的用户、昵称和音轨身份；模型 Speaker 标签不得覆盖真实身份。
- 转录底层保留 segment、word 和 ForcedAligner 精细时间轴，阅读层使用自然段展示；Benchmark 继续使用原始输出。
- 多模型测试支持暂停、继续、失败恢复与明确的空输出、超时、OOM、崩溃状态。
- Qwen3.6 本地整理通过受管 FreeToken Runtime 按需启动；用户不需要手动安装或理解 Sidecar 状态。
- 整理与上传是两个独立状态；未明确上传前，录音、转录和整理结果只保存在本地。

## 当前界面约束

- 设置页不再提供界面音效开关或音量调节；界面音效始终启用。
- 麦克风体检和说话模式位于主页麦克风菜单，设备选择固定在菜单底部。
- AI 模型卡片保持紧凑、状态区域稳定；技术细节按需展开，不用内部术语要求普通用户自行修复。
- 工作软件状态展示已移除，活动展示聚焦游戏和音乐。
- 不通过删除动画、降低动画质量或减少现有功能换取性能。

## 电话模式

- Windows 电话模式可配置按住或切换两种触发方式，支持空格、方向键、组合键和鼠标侧键。
- 原生助手枚举活动的所有输入/输出端点，启用前逐个确认静音；失败时保持上号音频保护并显示错误。
- 意外进程断开、锁屏或休眠不会自动解除静音；只有用户释放快捷键或正常退出软件才恢复。
- 独占音频、ASIO 或硬件绕过 Windows 共享端点控制的路径仍需硬件静音兜底。

## 验证边界

- 代码层验证应覆盖 typecheck、lint、单元/架构测试、native、五端音频与媒体、生产构建和 Windows CI 等价步骤。
- 15 分钟耐久检查记录 Main / Renderer 内存、进程、Track、AudioContext、AudioNode、定时器和监听器趋势；异常必须留下有界诊断记录。
- 自动化通过不等于真实设备音质、多人听感、游戏 FPS、GPU 峰值、物理五耳机或公网 TURN 已通过。
- 无法在自动化环境完成的项目必须标记为“代码层已完成，等待真实硬件实测”，不得写成已验证。
