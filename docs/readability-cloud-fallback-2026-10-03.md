# 弹窗可读性与云端备用

## 客户端修改

- 弹窗共用静态 14px 背景模糊与遮罩；面板为 98% 不透明，修正图片预览、音频菜单和原生 dialog 的覆盖样式。没有动画化 blur。
- 关于页素材图标、说明与操作按两列对齐；打开反馈与操作同行，支持开发独占一行。
- 每日回顾分短段落，15px／1.9 行高；最多三个真实趣事或互动，补充一条实际下次约定，重复内容去重。去掉逐人游戏时长、最高在线时刻和底部统计；奇数卡片末项横跨整行。
- 修正基础 `.modal-surface` 的 overflow 会覆盖 Tailwind 滚动规则的问题。390×780 与默认窗口完成回顾检查，内容可滚动、无横向溢出，背景文字不透出。
- 主窗口优先从保留的官方 PNG 设置 HWND 图标；素材窗口采用独立 PNG，创建／显示时重设图标，补上 dev 素材入口 relaunch 参数。正式 EXE 的耳机内嵌图标及桌面快捷方式正确，未清空 Windows 全局图标缓存。截图对应运行窗口的任务栏问题尚需新窗口实测。
- Windows 麦克风 ConsentStore 的应用及全局值只读核对为 Allow；软件 NotAllowed 提示指向隐私权限，NotReadable 不再直接认定为设备占用。本轮未修改权限、驱动、RØDE 配置或真实媒体路径。
