# 录音改名与卡片信息整理

## 本地修改

- 铅笔按钮原本在任何录音进行中都会禁用，用户点击没有解释；内联名称输入也与日期、播放器操作挤在同一行。现在点击直接打开独立的原生改名弹窗，名称获得焦点并选中，支持保存、取消和 Escape。录音期间可以编辑，结束后保存；保留已有录音生命周期保护。
- 保存期间防止重复提交；无效名称在输入框旁提示，保存失败保留草稿以便重试。离开录音页关闭弹窗。
- 原显示规则将与文件名一致的标题替换成“语音 NN”，会隐藏实际保存的自定义名称。新增可选 `isCustomTitle` 元数据标志，改名时由原有原子写入路径保存；旧记录仍能读取，历史非自动文件名直接展示，自动日期文件名维持简洁编号。跨语音记忆对账失败时，回滚同时恢复旧标题及标志。
- 录音卡片分行显示“录制时间 12:26”和“时长 6分42秒 · 4.9 MB”；按最新反馈，录制时间使用冒号，不追加“时、分”，避免与持续时长混淆。小时级时长有明确单位，窄卡片完整换行。
- 时长只读取当前已渲染录音的浏览器音频元数据，最多两个读取器、8 秒超时、最多 256 项内存缓存；文件地址、大小或修改时间变化后重新读取。离开页面取消读取并释放资源。失败显示“时长未知”，不估算时长、不播放音频，也不写入用户录音或目录。

## 验证范围

- 全工作区类型检查、相关文件 ESLint、架构预算检查与 `git diff --check`。
- 15 项现有 `recording-library.test.ts` 通过，包括事务改名的身份、时间、收藏和标记保留，旧录音及损坏元数据保护。
- 独立 Electron profile 的实际组件核对覆盖保存、防重复提交、无效名称、失败重试、录音期间的提示、原生取消、名称焦点及输入框尺寸、默认与自定义名称显示。卡片覆盖普通/小时级/未知时长，浏览器读取真实生成的两秒音频元数据。
- 隔离界面使用模拟保存回调和合成音频，不操作用户真实录音。记录在 `test-artifacts/recording-controls-review.json`，截图在 `test-artifacts/recording-controls-review.png` 与 `test-artifacts/recording-card-review.png`。
