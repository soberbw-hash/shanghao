## 已修复

| 问题                                     | 根因与处理                                                                                                                                                         | 验证                                                                   |
| ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------- |
| 鼠标组合键按住说话松开后不释放           | 松侧键时再次检查 Ctrl/Alt，先松修饰键会漏掉释放。现在由已经按下的侧键拥有释放；重复按下、移除绑定、游戏暂停监听和销毁均有收尾。                                    | 原生边界模拟复现后通过，未注册实际全局键。                             |
| 修改按住说话快捷键失败后旧键失效         | 先移除旧键，再尝试注册新键。现在新键注册成功才释放旧键，冲突保留原键。                                                                                             | 冲突、持有旧键期间失败和关闭检查。                                     |
| 游戏期间仍保留无用途鼠标监听             | 关闭按住静音后，暂停的鼠标绑定仍阻止停止钩子。现在识别游戏暂停状态；需要接收全局松键时继续保留监听。                                                               | 暂停、关闭按住静音、恢复绑定检查。                                     |
| 键盘组合键或失焦导致按住说话没有及时关闭 | 松键匹配依赖当前修饰键，失焦也没有释放。现在按实际主键释放，窗口失焦关闭发送，自动重复不能重新开麦。                                                               | Ctrl 先松、失焦、重复键、无关松键与清理检查。                          |
| 设置保存拒绝后按住说话模式却已改变       | 界面先修改发送状态，主进程拒绝时设置值没变，同步 effect 无法纠正。现在依据接受后的设置同步发送状态，保存异常显示失败。                                             | 页面入口检查及既有注册/设置回归。                                      |
| 麦克风处理切换失败后设置显示成功         | 先保存设置但没有检查设备替换的布尔结果，且不同控制可以并发。现在所有处理控制共用互斥事务；失败仅恢复本次仍拥有的字段，不覆盖后续设置。失败不播放成功音或记录成功。 | 成功、返回 false、异常、保存失败、并发阻止、失败后重试与后续编辑保护。 |
| 换设备/重建处理器后回声参考丢失          | 初次入房传入好友参考电平，重建时漏传。两个入口共用处理器配置，动态读取同一远端混音器参考，不改算法。                                                               | 两入口引用检查、动态电平与输入归属测试。                               |
