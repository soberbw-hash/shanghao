# 3.4.2 需求核对清单

以用户最后一次澄清为准：快捷按钮不分页、语音与音乐统一总开关、录制时间用冒号格式、清理不足十分钟。3.4.1 已交付项保留，本次发布纳入安装后反馈和房间记忆。代码与隔离检查完成，不将其当作真实设备听感或游戏兼容性结论。

| 需求                                   | 本次结果与证据                                                                                      |
| -------------------------------------- | --------------------------------------------------------------------------------------------------- |
| 切换、退出房间不闪加载、不突然变大变小 | 已验证房间先显示，后台刷新保留内容；见账号与房间反馈记录。                                          |
| 顶部信息放在中间                       | 顶部房间信息与按钮垂直居中。                                                                        |
| 左侧叶子不要硬边                       | 左侧渐隐处理；旧场景动画与页面隐藏规则保留。                                                        |
| 快捷按钮能放几个就显示几个，不分页     | 两行统一按可用宽度显示完整前缀，移除翻页；49 项隔离 UI 检查。                                       |
| 槽位可拖入、右键清空，保留空位         | 固定 8 个语音／音效和 5 个音乐槽位；清空不删除音频库资源。                                          |
| 总开关同时控制音乐和快捷消息           | 默认关闭，两区控件置灰禁用；房间鼠标按钮仍可用。                                                    |
| 总开关打不开                           | 一个绑定冲突不再关闭总开关；保留成功项与失败项配置，23 项隔离 UI 检查。                             |
| 关闭的快捷键不能出现按键提示           | 按总开关与单槽位实际启用状态显示提示。                                                              |
| 挂机返回保持原麦克风状态               | 保留离开前快照，恢复时不误解除手动静音。                                                            |
| 反复按住下键导致静音卡住               | 系统操作只执行最新待处理状态，恢复成功后解除软件门控；100 次连续操作夹具通过。                      |
| 反复进房总是小狐狸                     | 每次进房重新随机，避免重复，资料同步不重置房间角色。                                                |
| 录音铅笔无效                           | 可进入改名并保存。                                                                                  |
| 时间和总时长区分                       | 卡片显示“录制时间 12:36”与“时长 6分42秒”，分别排布。                                                |
| 清理废弃录音有用、备注简短、排版整齐   | 扫描不足十分钟或整段静音，预览、试听、选择后移入回收站；保护收藏、标记和读取失败项。                |
| 转录、整理、上传三步                   | 三个并列按钮，整理完成才能上传；文字为“上传到服务器”。                                              |
| 上传按房间隔离、日报可引用             | 摘要绑定录音原房间，服务端持久保存后 ACK；原始录音和本地标记不上传。                                |
| 自动整理／自动上传默认关闭             | 两个独立开关默认关闭，按需启用。                                                                    |
| 整理与问答模型合并、位置调整           | 合并选择默认房间云端，可切自定义 API；常用转录及整理设置在模型前面，顶部概览保留。                  |
| SVG 头像无法保存、限流错误             | 32 个简洁重绘头像，先预览再明确保存；内置头像按验证账号计数，自定义图片分支兼容检查通过。           |
| 好友上线提醒默认开启                   | 默认值开启，保留用户已保存的选择。                                                                  |
| 游戏事件自动标记                       | 默认开启，仅本机记录游戏启动／退出；回放可读发生时间和备注，音乐不纳入自动标记。                    |
| 最近提问可删除                         | 增加逐条删除入口。                                                                                  |
| AI 所有回答简洁，不附带无记忆提示      | 统一结论优先、保留重点；只有用户要求详细说明才展开。                                                |
| AI 分享到聊天显示游戏助手              | 机器人头像与“游戏助手”身份，保留 ACK、重试、分段和历史。                                            |
| 诊断需要自动修复                       | 启动与周期检查上号自身网络规则，确认缺失才尝试修复；必要的 Windows 授权无法绕过，取消后不反复弹出。 |
| 查找写“频道号”、按钮横排               | 输入提示与按钮最小宽度、禁止换行已调整。                                                            |
| 房间管理增加可编辑记忆                 | 手动文本与自动事实按永久 RoomID 隔离，房主编辑、当前成员读取；真实云端临时资料验证通过。            |
| GitHub 新功能截图及说明                | README 与 Release 说明补充当前生产组件的隔离演示截图。                                              |
| 更新公告易读                           | 五条重点、三个主题详情、原生模态焦点与关闭持久化；390px 窄窗口及历史重看等 11 项检查通过。          |

专题记录及各次定向证据见 [剩余工作](remaining-work.md)。正式版本、GitHub 工作流、资产校验、服务器和官网的最终状态见 [3.4.2 发布核对](release-verification-v3.4.2.md)。
