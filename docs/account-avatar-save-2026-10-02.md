# 头像保存限流修复（2026-10-02）

## 原因与修改

头像接口原来按 IP 限制十分钟最多八次，而界面每次选择立即提交；正常试选内置头像就可能耗尽额度，同一网络的账号也共用额度。错误提示固定写“一分钟后再试”，与实际窗口不符。

- 选择头像只做本地预览，点击“保存头像”才提交。保存前同步加锁，阻止连续点击和重复请求；保存失败保留已确认的账号头像及待保存选择。
- 内置头像先验证账号，再按账号限制每分钟六十次；接口另保留每 IP 每分钟一百二十次的外围限制。自定义图片上传仍按 IP 限制十分钟八次。
- 限流响应提供实际剩余秒数；通用提示不再承诺一分钟。账号、服务器或登录状态改变后，迟到的头像响应不会覆盖当前资料。
- 服务端成功、本地偏好写入失败时，只提示本地偏好未保存，不把已经同步的头像报告成失败。内置头像仍保留旧图片后端的 WebP 兼容路径。

## 验证

- 34 项定向检查全部通过，包括逐一保存 32 个内置头像、同 IP 账号隔离、换 token 不重置账号额度、无效身份拒绝、上传限流窗口及迟到响应保护。
- 隔离 Electron 的真实设置组件完成 16 项界面检查：预览不提交、连续保存只请求一次、失败保留旧头像并可重试、保存后重新打开选择一致。记录：`test-artifacts/avatar-save-review.json`、`test-artifacts/avatar-save-review.png`。
- 全量 smoke：968 项通过、1 项跳过、0 项失败；类型、对应 ESLint、格式、架构预算与普通构建通过。

## 生效边界

这是本地未发布修改，没有改动真实用户头像、凭据或账号数据。正式服务的限流代码及 32 个头像目录尚未部署，客户端尚未进入新安装包，不能把隔离夹具当作线上保存验收。部署后还需在隔离账号上确认保存、重新登录与房间资料同步。按照根目录 `AGENTS.md`，服务器部署需用户明确授权。
