# 账号与房间反馈收口

## 本地实现

- 内置头像失败的原因是主进程账号 IPC 丢失 `accountAvatarPresetId`，CloudBase 因此拒绝。现在显式校验并转交编号；图片压缩路径继续兼容照片上传及旧账号提供方。
- 十个旧 SVG 重绘为小尺寸可读的轮廓，新增二十二个，共三十二个。旧编号保留，无头像账号的默认哈希仍映射最初十个，避免新增目录改变既有身份。宽窗口三十二列，中等窗口十六列，小窗口八列／四列，完整铺满每行。
- 好友上线提醒默认开启，明确保存过的关闭选择保留。
- 自动标记游戏默认开启，在音频设置提供开关。主窗口持续监听现有游戏检测器，录音运行时记录启动／退出事件；重复状态、音乐和关闭开关后的事件不产生标记。首次快照只建立基线，不把已运行的游戏误报为新启动。每条录音最多两千个标记，取消订阅及迟到初始快照有防护。
- 游戏标记只进入本机录音标记文件，包含墙上时间和事件名称；未将这些标签加入云端整理或上传内容。旧偏移文件仍可读取。进度条标记支持悬停文字，回听／拖动靠近事件时显示备注；保留手动标记。
- 最近提问增加逐条小删除按钮；先完成本地写入再更新界面，写入失败明确提示。
- 快捷消息提示只在有效启用的绑定下显示按键，音乐提示同时遵守总开关。鼠标点击仍可使用。
- 成功加入后、导航之前，用已验证房间填充首页目录。刷新不清空已有内容；缓存按账号和服务器隔离，仅保留一份、最近二十条。加入期间账号改变时不填充新账号缓存。
- 每个新房间会话重新随机角色，避免连续请求同一个角色；房间冲突仍由服务器分配。内部重连保留当前角色，个人资料同步使用当前房间分配，避免又变回设置中的狐狸。

## 验证与边界

- 类型检查、ESLint、普通构建通过。桌面全量 smoke：935 通过、1 跳过，无失败。
- 五人音频与媒体自动化通过，覆盖后加入和恢复。这些结果不代表真实五台设备听感。
- 隔离 Electron profile 使用内存账号和房间，未操作真实录音、凭据或服务器。十项界面检查通过：退出首页立即出现房间、后台刷新尺寸一致、删除历史持久化、禁用快捷键无提示、三十二个 SVG 正常解码及选择保存、头像网格不越界、游戏启动只标记一次、音乐不标记、退出标记、关闭后不标记。600px 窗口另确认八列且无越界。
- 标记文件重读和手动标记兼容性、缓存隔离、五个角色抽取、默认开关与保存过的关闭选择在回归检查中覆盖。证据位于忽略目录 `test-artifacts/feedback-*.log/json/png`。
- 旧 Vite 弹窗检查夹具首次遇到构建 CSS 哈希更新，修正后仍遇到工具超时；本轮未将它记为通过。退出首页的加载行为已由独立 Electron 夹具通过。

本次未修改正式版本号、打包或部署。新增头像编号需要同批服务端共享目录更新后才能在正式服务保存；实际新游戏启动、已安装客户端连续退出／进入及真实账号同步仍需包含这些修改的下一批产物验收。此前 3.4.1 发布后的本地改动继续保留，不把旧安装包视为已包含这些修复。
