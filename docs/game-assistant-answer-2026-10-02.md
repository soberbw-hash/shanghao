# 游戏助手回答风格与聊天身份

## 本轮实现

- 房间问答与单条录音问答共享简洁规则：直接给结论，默认少量短行或要点，简单问题更短；明确要求详解、步骤或完整清单时才展开。保留必要限制与不确定性，不用截断答案强行满足字数。
- 不再把“没有检索到相关语音记忆”作为空候选资料输入模型。普通问题不讨论记忆检索；明确询问过去聊天而缺少证据时简短说明无法确认。兼容清除带正文答案的冗余检索开场，保留正文和实际来源。
- 联网问答同样采用简洁风格，准确区分游戏、模式与版本。录音整理的完整结构与内容要求保留，不将问答字数约束施加到整理流程。
- AI 分享消息使用 `game-assistant:<UUID>` 的客户端消息标识；既有信令字段可回传与持久化，接收界面显示“游戏助手”和既有机器人头像。本地与远端气泡统一显示样式，与普通用户消息分别分组。
- 身份标识只负责展示。实际发送者仍由服务器验证，ACK、重试、去重、撤回权限沿用原作者。没有新增虚假房间成员、伪造认证身份或改变语音媒体路径。

## 当前边界

这是 3.4.1 安装后继续开发的本地修改，尚未打包、发布或部署。客户端提示词在新客户端生效，云端系统提示词随未来服务部署生效。旧客户端不识别新增展示标识时仍显示原分享者，但可安全接收消息。历史旧分享消息没有该标识，不推断或批量改写其作者。

模型请求的定向检查使用隔离提供方夹具，没有调用线上模型评价实际答案质量或最新游戏知识。提示词规定核实时效信息，不代表已验证所有游戏版本答案。没有操作用户真实聊天、录音、设置或模型数据。
