# ShangHao v3.4.3 发布核对

2026-10-03 按用户授权与桌面发布流程，核对 GitHub 和 CloudBase 当前正式版本均为 3.4.2，目标 3.4.3，构建号 2026.10.03.2，协议保持 7。

本地已有修改全部保留。本批包含 60 个游戏显示器画面、本地上号素材及滚动修复、简化并统一自动房间记忆、适合上号的分享来源预览交互。实现与本地验证完成后，最后发布 3.4.3。

## 本地验证

游戏与房间记忆 35 项定向检查、上号素材原生检查 17 项、隔离 Electron 界面与竞态检查 26 项已通过。工作室主页面和放大窗口的实际滚动正常，分享选择、取消、重复确认及迟到枚举均已覆盖。

用户随后反馈桌面入口打不开：直接加载 `desktop.cjs` 时 Electron 默认加载器不保证 `require.main === module`，导致只启动运行时、没有创建工作室。新增明确的 `launch.cjs` 与独立 package 入口，快捷方式和任务栏重启都指向该应用目录；保留审核数据，只结束已确认没有窗口和 Renderer 的旧空进程。修复后用户确认窗口已打开，新增入口回归检查。

全量 smoke 为 990 项：989 通过，1 项原有跳过，0 失败。typecheck、lint、Rust 格式与测试、生产构建、迁移、N-1 升级、运行健康、手机麦克风、音频 Worklet、Windows 屏幕捕获及五端音频/媒体检查已通过。架构原有预算未提高。

最终本地 Windows 候选包运行时检查通过：安装包 184.28 MiB，解压后 486.59 MiB，app.asar 57.16 MiB，均在既有预算内。正式 GitHub 构建产物与云端部署结果在发布阶段单独核对。
