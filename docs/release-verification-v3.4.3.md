全量 smoke 为 990 项：989 通过，1 项原有跳过，0 失败。typecheck、lint、Rust 格式与测试、生产构建、迁移、N-1 升级、运行健康、手机麦克风、音频 Worklet、Windows 屏幕捕获及五端音频/媒体检查已通过。架构原有预算未提高。

本地 Windows 候选包运行时检查通过：安装包 174.01 MiB，解压后 475.14 MiB，app.asar 57.15 MiB，均在预算内。正式 GitHub 构建产物与云端部署结果在发布阶段单独核对。

## 数据与范围

自动记忆保留历史事实证据，以一个可编辑文本显示；数据版本保持 1，新增可选字段与旧数据兼容。保存仍有 revision 校验，刷新保留未保存编辑，各房间按永久 RoomID 隔离。较旧服务器若不支持统一文本会明确拒绝保存，避免静默丢失修改。

素材工作室有独立本地 profile，保存意见及导入导出不进入正式安装包。文件导出重名不覆盖、资产路径限制、损坏意见原文件保留。截图使用生产组件和虚构资料，没有使用真实聊天、录音和账号。

屏幕分享仅调整选择交互，保留原捕获与 Track 生命周期。实际系统声音仍为电脑整体音频，没有承诺只捕获单个应用。
