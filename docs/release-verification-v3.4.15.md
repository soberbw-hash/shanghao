# 上号 3.4.15 发布核对

2026-10-27，候选版本 3.4.15 / 2026.10.27.2。用户已授权完成后推送和打包，独立审核仍暂停。发布前实查 GitHub 最新正式版与 CloudBase release.json 均为 3.4.13。

本轮涵盖内置云端 AI、默认 Qwen 0.6B 自动准备、后台队列恢复及自动摘要、临时联机入口和顶层管理窗、电话模式及状态统一、LOL 等待房间与迎宾门。数据保留，开发者凭据不进入源码和安装包；不自动上传录音摘要到房间。

当前已完成的定向验证：云端任务恢复与默认模型策略、临时身份和创建/加入路径；隔离 Electron 验证 360/420/600 宽度不溢出、SVG 头像单行、格式化房间码输入、重复打开、已登录头像继承、管理弹窗位于顶层。实际 Windows 音频夹具验证放歌开始/停止及 PCM 输出。
