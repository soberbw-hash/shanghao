## 问题归类与处理

1. **检测器误报：**Qwen3 1.7B 与 FireRed 各有 1 个自然重复语气被旧规则误判为循环。已经收紧重复字符判断，并用保存的原始输出重新通过质量规则；旧矩阵文件保留原始标记以便追溯。
2. **模型输出异常：**GLM 与 Fun 的片段确实发生高长度重复生成。提示词、语言与数值精度针对性复测没有恢复正常。当前应避免将这两款模型作为长录音唯一结果来源。
3. **运行器边界：**MOSS 的 `OutputTruncated` 是可修的分段策略问题，修复已通过假解码器测试和 4 个真实异常片段验证。空白结果仍需按实际音频内容判断，暂不能给出全量稳定性结论。
4. **静音或漏字：**公共 VAD 与不同模型的空白输出只是复核线索。没有听完每个片段，也没有人工真值，不能直接把全部空白算作模型漏字。

## 精简建议

现阶段先保留 **ARK、Qwen3 1.7B、Qwen3 0.6B、Paraformer** 作为长录音比较池：ARK 提供完整覆盖，Qwen3 1.7B 用来观察内容质量，0.6B 用于轻量对照，Paraformer用于速度对照。FireRed、GLM、Fun 与 MOSS 可以暂时从“优先推荐”候选中后移；这只是评测建议，没有删除任何模型、改变用户选择或改动当前默认推荐。最终是否减少模型入口，应在少量人工听写核对、不同语音场景和新 MOSS 运行器全量复测之后决定。
