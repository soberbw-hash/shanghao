# 支持的游戏

本页与上号当前游戏检测规则同步。游戏状态只识别有明确进程证据的受支持游戏。

游戏显示器使用统一的 MOBA 地图、射击、休闲、赛车和冒险场景插画，配合名称与当前电脑程序的图标，避免小屏幕封面难辨认及重复闪动。这些是装饰画面，不是游戏实时画面或进度。上号只把压缩后的图标和下列固定名称同步给同房间好友，不发送文件路径。

## 识别说明

新增常用游戏：火箭联盟、泰拉瑞亚、哈迪斯、Warframe、命运 2、绝地潜兵 2、漫威争锋、黎明杀机、致命公司、R.E.P.O.。英雄联盟识别 `LeagueClient` / `LeagueClientUx` 大厅及比赛进程；GTA V 同时识别增强版。通用 `World` 和 `Discovery` 进程需额外标题或路径证据，避免误报。

当前验证覆盖进程夹具、前后台切换与名称同步；不能代表所有游戏版本、地区服和反作弊环境的实机通过。独占全屏由游戏占有显示面，外部窗口不能保证覆盖；无边框窗口使用无焦点置顶恢复。

## 模式、英雄与组队人数

仅有进程信息无法获取这些详细状态。Discord Rich Presence 由游戏或集成主动提供活动数据；上号也可通过游戏官方提供的接口接入。Riot 的本地 Game Client API 可在比赛中提供部分数据，客户端大厅的 League Client API 属于非官方支持接口，可能随更新变化。本版不猜测排位模式、英雄或队伍人数，也不抓取其他玩家的账号凭据；同房好友的详情仍需各自客户端取得真实数据后主动同步。

参考：[Discord Rich Presence](https://discord.com/developers/docs/social-sdk/index.html)、[Riot 本地客户端接口](https://developer.riotgames.com/docs/lol)。

- 游戏按明确的进程名匹配；具体游戏优先于平台客户端，普通 Java 程序不会被当成游戏。
- Spotify、Apple Music、网易云音乐和 QQ 音乐作为独立的音乐状态处理。
- 软件升级不会清除本地聊天历史、录音目录或每位好友的本地音量设置。
