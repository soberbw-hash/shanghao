# 上号素材工作室

独立的本地审核工具，复用真实房间组件和游戏显示器，不进入上号安装包。

## 日常打开

双击桌面 **上号素材工作室**。关闭或重启电脑后仍可打开，不需要启动开发服务器。
程序和素材快照位于桌面 `上号素材审核` 文件夹，自带 Electron 运行环境；请保留整个文件夹。

- 查看房间组件、60 款游戏画面、头像及原始图片；支持搜索、筛选和纵向滚动。
- 点击卡片放大，游戏同时显示实际 `110 × 70` 尺寸。
- 复制图片、下载原素材；时钟、日历等组合组件可导出当前静态效果图。
- 填写意见后点击 **保存意见**，关闭重开后继续审核。
- **导出意见**生成 JSON 备份；**导入意见**合并记录，同一素材保留较新的意见。

记录位于 `%APPDATA%\ShangHaoAssetStudio\reviews.json`，上一次有效记录留在 `.backup`。
读取失败时保留原文件并阻止页面直接覆盖；导入有效备份恢复后，原损坏文件另留在 `.unreadable`。
重新生成素材不会删除审核意见。下载时重名文件不会被覆盖，换个文件名即可。

## 更新素材快照

```powershell
corepack pnpm --dir apps/desktop build:renderer
corepack pnpm review:assets
```

修改后重新生成，随后关闭工作室重新打开，或按 `Ctrl+R` 刷新。浏览器预览可运行：

```powershell
corepack pnpm review:assets --serve
```

地址为 `http://127.0.0.1:45741`，浏览器使用自己的本地记录；完整复制与下载能力以桌面工作室为准。

原图在 `apps/desktop/src/renderer/src/assets/`，日期、时钟指针与游戏场景等叠加逻辑在 `components/room/`。审核页复制原图供查看，不修改源素材；旧图与当前效果分别说明。天气使用内存预览，页面不连接房间、不读取账号、聊天或录音。

来源链接、官方场景和平台设计的区别见游戏画面详情；保留的旧素材有独立标签。
